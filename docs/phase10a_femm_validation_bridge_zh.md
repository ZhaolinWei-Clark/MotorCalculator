# Phase 10A — FEMM 验证桥接（FEA Validation Bridge）

**状态**：`FEA_BRIDGE_IMPLEMENTED_SOLVER_BLOCKED`
**分支**：`codex/phase10a-femm-validation-bridge`
**应用版本**：`1.0.0-rc3`（Phase 10A 不修改版本号）

> **本阶段不声称任何 FEA 验证通过。** 本机未安装 FEMM，没有执行过任何场求解，
> 因此不存在 `FEA_VALIDATION_PASS`，也不存在任何真实 FEA 数值。

---

## 1. 本阶段做了什么、没做什么

Phase 10A **不是**增加公式，而是搭建一条把现有解析公式交给独立数值电磁求解器
检验的通路：

```
MotorCalculator 解析结果
  → 结构化验证案例（FEAValidationCase）
  → FEMM 模型生成（几何 / 材料 / 绕组 / 网格 / 边界）
  → FEMM 执行（可用时）
  → 结果提取（磁链、力）
  → 解析 vs FEA 对比
  → 验证证据记录（NUMERICAL_FEA）
  → 工程验证报告
```

关键产出不是「FEMM 能跑」，而是：

> **在明确匹配的假设下，解析预测与 FEA 相差多少。**

**未做**：任何多物理场 FEA；任何三维 FEA；任何自动校准；任何对解析物理的修改。

## 3. 集成方式的选择

| 方案 | 评估 | 结论 |
|---|---|---|
| **subprocess + 生成的 Lua 脚本** | FEMM 原生自动化接口；不需要额外 Python 包；脚本是纯文本，可在无 FEMM 的机器上生成、检查、版本化、导出 | **采用** |
| `pyfemm` / `femm` Python 包 | 仍然只是对同一 Lua/COM 接口的封装，且仍需要本机安装 FEMM；引入一个当前不可用的依赖 | 探测并记录，不作为依赖 |
| COM 自动化 | 需要注册的 FEMM 类型库；比 Lua 更脆弱，且不便于离线生成 | 不采用 |
| 云端求解 | 明确禁止引入云依赖 | 不采用 |

`subprocess + Lua` 的关键好处：**案例生成与求解解耦**。
未安装 FEMM 的用户仍可生成完整的求解脚本并复制到有 FEMM 的机器上运行。

## 4. 首个参考拓扑的选择及理由

### 4.1 为什么不是径向磁通 PMSM

审计 `MotorAnalysisInput` 后确认：**应用的输入模型里根本不存在径向磁通拓扑**。
schema 全部是轴向磁通量（`outer_diameter_m` / `inner_diameter_m` 环形、
`air_gap_per_side_m` 双气隙、`coil_height_m`），
`DEFAULT_TOPOLOGY_ZH = "双转子、单定子、双气隙"`。

因此建立一个径向磁通参考，等于去验证一台 **MotorCalculator 根本算不出来的电机**。

### 4.2 为什么二维中径展开切片是站得住脚的

解析极面积为

```
A_pole = (π / 2p) · (R_out² − R_in²) · α_p
```

而 `(R_out² − R_in²) = (R_out + R_in)(R_out − R_in) = D_avg · L_r`，所以

```
A_pole = (π·D_avg / 2p) · L_r · α_p = τ_p · L_r · α_p
```

**恒等于**极距 `τ_p`、深度 `L_r` 的直线电机极面积。

也就是说：**解析磁路本身就已经是一个中径展开模型**，
二维平面切片不是新引入的近似，而是它精确的几何对应物。
切片相对解析模型**多出来**的是：二维场扩散、极间漏磁的几何求解、真实开槽。

### 4.3 磁钢排布由解析方程本身确定

解析磁动势为 `2·(B_r/μ0)·h_m/μ_r`，磁阻为一个 `h_coil + 2g` 气隙加 `2·h_m` 磁钢。
**两块磁钢串联跨越一个贯穿定子的气隙** —— 这唯一对应
**轴向贯穿（N-S 相对）的双转子排布**。几何按此建立，
从而保证被检验的是那条方程所描述的机器，而不是另一台。

### 4.4 无铁芯 vs 有铁芯

| | 无铁芯（coreless） | 有铁芯（cored） |
|---|---|---|
| 可支持性 | `SUPPORTED` | `PARTIALLY_SUPPORTED` |
| 解析气隙 `h_coil + 2g` | **就是**两磁钢面之间的物理距离 | 即使有铁芯仍含线圈高度 |
| 磁钢排布 | 由解析方程唯一确定 | schema 未声明 N-N 还是 N-S |
| B-H 曲线 | 不需要（无定子铁） | 需要引入解析模型中不存在的材料 |
| 线性度 | 线性 | 可能饱和 |

因此**首个参考案例采用无铁芯 SSDR**：它是解析磁路能唯一映射到一个物理几何、
不需要编造 B-H 曲线、且保持线性的唯一变体。

有铁芯路径**已实现**并可生成案例，但被标记为 `PARTIALLY_SUPPORTED`，
并附两条显式近似标签：

- `CORED_AFPM_MAGNET_ARRANGEMENT_NOT_DECLARED_IN_SCHEMA`
- `ANALYTICAL_GAP_INCLUDES_COIL_HEIGHT_EVEN_WHEN_CORED`

### 4.5 保真度等级

FEMM 是二维求解器，对轴向磁通电机只能给出简化磁参考。
沿用 Phase 7H 的词汇，本桥接固定为 **`FEA_TIER_3`**，
**不构成任何三维 FEA 等价性声明**。

切片结构性无法表示的效应（记录在案例上）：

- 极距、线圈边宽、磁钢宽度随半径变化；只求解中径
- 内外半径边缘 fringing 与端部漏磁缺失
- 端部绕组几何、其漏感与电阻缺失
- 局部线速度 `ω·r` 随半径变化；只表示 `ω·r_mean`
- 磁钢覆盖或线圈形状的任何径向变化缺失

## 5. 案例 schema 与哈希

`FEAValidationCase`（`phase10a.fea.case.v1`）显式记录：

拓扑、槽数、极对数、相数、定子/转子尺寸、气隙、磁钢尺寸与材料、
绕组数据（匝数、并联支路、线圈节距、逐线圈相位与极性、绕组系数及其来源）、
电流、转子角扫描、转速、温度假设、单位、模型版本、
网格策略、对称性方案、可支持性与全部近似标签。

**没有任何未声明的默认值。** schema 中不存在的量必须显式提供，
否则案例状态为 `NOT_ENOUGH_GEOMETRY`（见 §7）。

### 两个独立的摘要

| 摘要 | 覆盖 | 失效含义 |
|---|---|---|
| `case_id` | 几何、材料、绕组、工况、网格策略、对称性、schema 版本、求解器族 | **被求解的机器变了**，旧 FEA 数值作废 |
| analytical fingerprint | 解析预测 + 应用版本 | FEA 数值仍有效，但**对比**必须重算 |

浮点数经 `float.hex()` 精确哈希，摘要不会随十进制格式漂移。

## 6. 材料映射

| 项 | 来源 |
|---|---|
| 磁钢 `B_r` | 输入 |
| 磁钢 `μ_r` | 输入 |
| 磁钢 `H_c` | `B_r / (μ0·μ_r)` 推出 |
| 铜电导率 | 与解析绕组电阻**同一条**电阻率温度公式 |
| 空气 | `μ_r = 1` |
| 定子铁芯 | 有铁芯时按策略：线性高磁导率（默认）或具名库 B-H |
| 转子磁轭 | 线性高磁导率 |

### 已记录的失配（不编造）

- 解析磁路**完全不含铁磁阻，也不含任何 B-H 数据**；FEA 铁芯磁导率是显式声明的 FEA 专用参数
- 解析模型不含转子磁轭厚度；同样是显式声明的 FEA 专用参数
- 磁钢与钢的电导率对静磁求解无意义，不传递
- 解析 `leakage_factor` 是集总标量，没有场求解对应物；求解器按几何解析漏磁
- **解析 Carter 系数是按槽型名称查表得到的固定值，完全忽略所输入的槽口宽度与气隙**；求解器解析真实开槽

线性铁芯策略默认，理由是：解析模型隐含「铁无磁阻」，
线性高磁导率正是该假设的 FEA 表示，从而把对比聚焦在气隙与漏磁建模上，
而不是混入解析模型从未声称建模的饱和。
选择可饱和库 B-H 时会额外记录一条失配：其物理内容多于解析模型，
因此差异不能单独归因于解析模型。

## 8. 绕组映射：为什么按线圈而不是按槽

槽电势星形图给出的是每个**线圈**的相位与串联方向。一个线圈有两条边，
只有这一对边合起来才是零净电流。

对整数槽分布绕组，星形图恰好把 `+`、`−` 边放进不同槽，
「每槽一层」的模型看起来没问题。但对 `q = 0.5` 的分数槽绕组
（例如本参考设计的 `Q=24, 2p=16`），槽角只有 0°/120°/240°，
**A 相的每一条线圈边都落在同一个带内**，全为 `+`。
此时「每槽一层」会让该相在求解平面内带有非零净电流，
得到的磁链根本不是线圈磁链。

因此本桥接**显式建立双层**：线圈 `c` 的去边在槽 `c`，回边在槽 `(c + y) mod Q`。
每相在平面内的净安匝被断言为 **0**（回归测试锁定）。

belt 分配使用与 `motor_core.winding_factor.build_slot_star` **完全相同**的
精确整数算术（浮点边界会静默打乱 `Q=24, 2p=4` 这类绕组），
并由回归测试逐槽逐符号比对，确保两者不会分叉。
**`winding_factor.py` 未被修改**，绕组系数语义不变。

槽内导体按**均质载流区域**建模，携带相电流乘以带符号匝数；
它**不是**逐根导线的排布几何，
解析的近似裸铜槽占比也**不是**填充图。

## 9. 边界与对称性

展开后的两个圆周端点是**同一个物理位置**，因此施加**周期性边界**，
而不是规定势 `A = 0`（后者会在机器内部制造一道虚假的磁通壁垒）。
远场上下边界为 `A = 0`。

对称扇区**总是被推导并记录**（`gcd(Q, 2p)`、扇区槽数与极数、
是否对齿槽有效），但**默认不启用**，默认求解完整圆周：
错误缩减的扇区会静默抹掉齿槽内容，而本机没有求解器可以发现这一点。

旋转会让磁钢跨过 x=0 的周期缝；跨缝磁钢被**拆成两块**发出，
面积守恒由回归测试锁定。

## 10. 网格策略

尺寸由物理决定，不是固定单元预算：

| 区域 | 尺寸 |
|---|---|
| 气隙 | `g / 3` —— 气隙支配全部被验证量 |
| 全局 | `τ_p / 12` |
| 磁钢 | `min(h_m/4, τ_p/12)` |
| 磁钢边缘 | `min(h_m/8, τ_p/24)` —— 决定磁通波形的谐波含量 |
| 槽口（有铁芯） | `max(w_open/4, g/6)` |
| 绕组 | `h_coil / 4` |
| 远场空气域 | 全局的 6 倍（刻意粗化） |

**单一网格不作任何收敛声明**：`convergence_claim = NO_CONVERGENCE_CLAIM_SINGLE_MESH`，
构造器会拒绝任何声称已收敛的单网格策略。
收敛判定仍由 Phase 7H 的 `assess_mesh_convergence` 三级网格门控独占。

## 11. 转子角采样

每个位置都是一次完整场求解，因此采样点数由**每个目标真正需要分辨的最高谐波**推出，
而不是默认取 360。

| 目标 | 跨度 | 最高谐波 |
|---|---|---|
| 空载反电动势 | 一个电周期 `360/p` | `max(13, ⌈Q/p⌉+1)` 次电谐波 |
| 平均转矩 | 一个电周期 `360/p` | `max(18, ⌈Q/p⌉+1)` 次电谐波 |
| 齿槽转矩 | 一个齿槽周期 `360/lcm(Q, 2p)` | 3 次齿槽谐波 |

每周期 4 个采样点（Nyquist 需要 >2，留出求导裕度），下限 24，上限 720 次求解。

**反混叠**（Phase 9B 的教训）：若采样点数与跨度内的物理事件数（槽经过次数）
存在公因子，采样会落在每个事件的同一相对位置上，波形塌缩、峰值被静默低估。
采样点数会持续加一直到与事件数**互质**。

本参考设计（Q=24, p=8）：反电动势 52 点、转矩 73 点、齿槽 24 点，
三个目标合计 **149 次场求解**。

## 12. 三个验证目标

### 12.1 空载反电动势 / Ke

零电流，逐位置静磁求解，从电路属性读取相磁链 `λ(θ)`，
再由**谱微分**得到

```
e = ω_mech · dλ/dθ_mech
```

用谱微分而不是有限差分：波形在采样跨度上严格周期，
而导数正是被验证的量，差分格式会把自身的截断误差加进被测数字里。

**速度标定**：静磁磁链与转速无关，因此反电动势**严格线性**随转速变化。
这是公式本身的性质，不是这里额外加的近似。
明确记录：**不含涡流反作用、不含频率相关磁导率、不表示任何时域旋转效应**。
不假装静磁 FEMM 直接求解了时域旋转。

对比基准全部显式：相 RMS、线 RMS（平衡 Y 的非三次谐波内容）、
每机械 rad/s 的 Ke。

### 12.2 平均电磁转矩

受控电流激励，逐位置求解，取转子块的**加权 Maxwell 应力张量**周向力 `F_x`，
按 **`T = F_x · r_mean`** 转为转矩（平面模型是直线电机，该换算显式记录）。

电流为解析相电流 RMS，电流矢量在 `q` 轴（`id = 0`），
与解析转矩常数的定义工况一致。

> **已记录的限制**：相 A 轴与转子 d 轴的电角度对齐关系需由一次空载扫描测得。
> 未提供时按 0 假设，并在 provenance 中记录警告
> `the electrical alignment ... was assumed to be zero and not measured`，
> 不会静默宣称这就是 `id = 0` 工况。

### 12.3 齿槽转矩

零定子电流，扫描一个齿槽周期，提取正峰、负峰、峰峰值、RMS 与基波幅值。

> **必须明确**：解析齿槽峰值是 `k_cogging_peak × 额定转矩`，
> 其中 `k_cogging_peak` 由**用户输入的齿槽系数**导出，**不是**场计算量。
> 因此这项对比检验的是**所输入的假设**，不是一条物理公式。
> 该说明作为 `ANALYTICAL_COGGING_IS_A_USER_SUPPLIED_RATIO` 随每次对比一起输出。

无铁芯定子按构造无齿槽，解析预测恒为 0，
此时 FEA 对比测得的是**求解器噪声底**，而不是物理齿槽幅值；
案例备注中显式声明。非平凡的齿槽对比属于有铁芯路径，
而该路径当前为 `PARTIALLY_SUPPORTED`（见 §4.4）。

## 13. 对比指标与判定

每个量输出：`analytical_value`、`fea_value`、`absolute_error`、`relative_error_percent`；
多样本时另有 bias / MAE / RMSE。

**零分母**：当解析值实际为零（如无铁芯齿槽），**不报告相对误差**，
只报告绝对差，并在需要时相对一个显式命名的参考尺度（如额定转矩）分类。

**判定是描述性的，不是 PASS/FAIL**：

`CLOSE_AGREEMENT` / `MODERATE_DEVIATION` / `LARGE_DEVIATION` /
`NOT_COMPARABLE` / `INSUFFICIENT_DATA`

数值判定带**明确标注为项目临时约定**：

> `PROVISIONAL_PROJECT_BANDS`：close ≤ 5%、moderate ≤ 20%、large > 20%。
> 这是本项目为便于阅读而选的分档，**不是行业容差，也不是通过/失败判据**。

### 差异归因

每次对比附一组**候选原因**（明确标注为候选，未经证实的归因），例如：
集总磁路简化、`leakage_factor` 是拟合替身、Carter 查表忽略槽口宽度、
绕组系数仅取基波正弦投影、二维切片缺边缘 fringing、
电枢反应与局部饱和缺失、`T = F_x·r_mean` 只用中径、网格离散。

## 14. 不做自动校准

**`AUTO_CALIBRATION_ENABLED = False` 是常量，没有任何代码路径可以翻转它。**

- 不自动修正 `B_r`
- 不自动拟合气隙系数
- 不自动拟合损耗系数
- 不自动修正绕组系数

回归测试逐文件扫描整个 `fea/` 包，禁止出现
`curve_fit` / `least_squares` / `minimize(` / `polyfit`，
并要求 `calibrat` 一词只能出现在拒绝、禁用常量或「仅提案」的语境里。
另有一条测试断言：跑完一次验证后，解析结果对象逐位不变。

任何校准只能是**人工审批的提案**。

## 15. 证据与置信度

新增 `EvidenceClassification.NUMERICAL_FEA`，与 Phase 7H 既有分类并存，
共用同一套证据词汇而不是另起一套。

> **FEA 是独立的数值证据，不是物理实验。**
> `NUMERICAL_FEA` 永远不等于 `EXPERIMENTAL_MEASUREMENT`；
> 证据记录若被构造成实验测量会直接抛错。

置信度政策：

> 单个一致的 FEA 案例，是关于**一个设计、一个工况、一个保真度等级**的证据。
> 它本身不足以把模型置信度提升为 HIGH。置信度仍受限于：
> 独立案例数量、所覆盖的参数范围、所求解拓扑是否与目标设计一致、
> 求解器自身的假设，以及**实验测量依然缺位**这一事实。

Mock 数据**永不可作为证据**：`is_mock` 是必填字段，
`MockFEASolver` 必须自报为 mock（provenance 构造器双向校验），
对比与证据记录都会把它标为不可采信。

案例过期同样使证据不可采信，且区分两种过期：
「机器变了」与「解析预测变了」。
