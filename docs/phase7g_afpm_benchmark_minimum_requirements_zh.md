# Phase 7G AFPM 基准最小要求锁定

## 1. 用途与边界

本文件锁定 Advanced AFPM 径向切片反电势模型进入外部比较前的最小证据要求。Phase 7G 只获取和审计证据，不修改生产公式、Advanced AFPM 公式、GUI、动态模型或校准参数。

候选来源只有在以下字段均由来源直接给出或通过明确、可复核的 SI/计数变换安全推导时，才可通过现有 `AFPMCompletenessGate`。项目默认值、通用磁体牌号属性、经验绕组因子、模型输出反推值均不得补缺。

## 2. 机器身份

- 来源必须明确指向一台可识别的 AFPM 机器或一个可复现的 FEA 模型。
- 多篇论文只可合并为一个来源族，前提是作者/项目、拓扑、主要尺寸、极数、绕组和运行点等重复特征足以证明为同一台机器。
- 若机器身份不能闭合，跨论文字段不得拼接。

## 3. 拓扑与几何

必需字段：

- AFPM 拓扑：SSDR、DSSR 或单边结构。
- 定子数、转子数、有效气隙数、绕组位置和磁体位置。
- 内半径、外半径。
- 每侧物理气隙，以及模型所需的有效非磁性气隙。两者不可无说明互换。
- 磁体轴向厚度。
- 极对数。
- 可映射到模型的磁体覆盖率：统一磁极弧比，或覆盖整个有效半径区间的径向磁体轮廓。

仅有平均半径处覆盖率、照片尺寸、未标尺 CAD 图或圆柱磁体的单个平均占空比，不足以建立径向覆盖轮廓。

## 4. 绕组网络

必需字段：

- 每线圈匝数。
- 每相线圈数、每支路串联线圈数、并联支路数，或等价的每相有效串联匝数。
- 定子间串联/并联/独立关系。
- Y/Delta 相连接。
- 绕组类型与可追溯的基波绕组因子 `kw`，或同时明确的 `kp`、`kd`。

仅有槽数、`q=1`、集中/分布绕组标签或线圈外形，不能自动生成 `kw`。

## 5. 磁体材料

必需字段：

- 源机器工作条件对应的剩磁 `Br`。
- 磁体相对回线磁导率 `mur`，或来源模型明确采用的数值假设。
- 若来源声明温度修正，则需给出运行温度与修正规则。

只给出 NdFeB 或 Nxx 牌号而无数值，不允许查通用产品表自动补入。

## 6. 运行点与外部参考

必需字段：

- 机械转速。
- 反电势测量边界：相/线、相对中性点/端子。
- 数值类型：峰值、总 RMS、基波 RMS 或完整波形。
- 波形族与谐波说明。
- 外部参考值及测量/FEA/解析来源层级。
- 页码、表格/图号、单位和不确定度；不确定度未报告时必须明确标记不可得。

当前 Advanced AFPM 求解器输出基波相 RMS。总 RMS 且含显著谐波的来源，不能仅用 `sqrt(2)` 或 `sqrt(3)` 强制变为基波参考。

## 7. 证据层级

- **实验层**：原型机测量，机器身份和测量语义闭合。
- **FEA 层**：完整、可复现且字段满足 gate 的 AFPM FEA 个案。只能标记为 FEA 验证，不能宣称实验验证。
- **解析层**：可用于公式一致性检查，不能单独证明外部物理精度。

## 8. Gate 决策

- `READY`：现有 gate 无缺项，且外部值与模型输出语义可直接比较。
- `PARTIAL`：只适用于现有 gate 对尚无物理路径但已有参考的指标；反电势 gate 当前不以 `PARTIAL` 放行。
- `BLOCKED`：任一必需字段缺失、歧义、机器身份未闭合或外部语义不可安全映射。

评分高不代表 `READY`。质量评分只用于排序后续获取工作，不能覆盖 completeness gate。
