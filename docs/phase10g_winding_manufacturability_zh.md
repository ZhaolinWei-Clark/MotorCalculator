## 1. 角度约定（Step 1）

项目中至少有九个角度量，此前没有一处写明它们的零点。**权威约定**：

| 量 | 零参考 | 正方向 | 单位 | 基准 | 消费者 |
|---|---|---|---|---|---|
| 转子机械角 `θ_m` | 几何生成器自身原点（展开切片跨度的角落） | +x（周向） | 度 | 机械 | `build_slice_model` |
| 转子电角 `θ_e` | 同上 | 同上 | 度 | 电（`θ_e = p·θ_m`） | 采样、谐波 |
| **A 相磁轴** | **由 A 相导体分布的基波投影相位导出** | +x | 度 | 电 | 励磁基准 |
| B / C 相磁轴 | A 相轴 ∓120°电 | +x | 度 | 电 | 三相对称 |
| **转子 d 轴** | **由磁钢极性分布的基波投影相位导出** | +x | 度 | 电 | 励磁基准 |
| 转子 q 轴 | d 轴 + 90°电 | +x | 度 | 电 | `id=0` 判定 |
| **励磁基准** | **d 轴相对 A 相磁轴** | — | 度 | 电 | `balanced_phase_currents` |
| 电流相位角 | 相对 d 轴，90° 即 `id=0` | — | 度 | 电 | 工作点 |
| FEMM 几何 x 轴 | 展开跨度起点 | +x | 米 | — | 网格 |

**一个电气约定贯穿全部**：一个极距 = 180°电，因此周向波数
`k = π / τ_p` 可以把「米」直接变成「电弧度」。

## 2. 励磁对齐的推导（Step 2）

### 2.1 缺陷成因

`balanced_phase_currents` 的文档字符串写明：其电角度是
**「从 A 相磁链最大值量起」**。而适配器传入的是 `p × θ_m`，
其零点是**几何生成器的原点**，与 A 相磁轴毫无关系。

Phase 10F 实测两个零点相差 150°电——这就是那个数字的全部来历。

### 2.2 推导

两个轴都是**基波投影的相位**：

```
A 相磁轴：  arg( Σ_r  signed_turns_r · exp(j·k·x_r) )          （按有符号匝数加权）
d 轴：      arg( Σ_m  polarity_m · width_m · exp(j·k·x_m) )    （按极性与宽度加权）
```

其中 `k = π / τ_p`。按宽度加权是为了让跨越周期缝被切成两块的磁钢，
其贡献与整块完全一致。

### 2.3 那个 90°

**第一次推导落后了整整 90°**（给出 60° 而非 150°）。原因是物理的，不是凑数：

磁钢相量定位的是**法向气隙磁密**的基波，
但绕组链的是**磁矢位**，而平面问题中 `B_n = −∂A/∂x`。
由 `B_n` 还原 `A` 是一次空间积分，**积分使基波旋转四分之一周期**。

因此：

```
θ_d(相对 A 相) = arg(M) − arg(W) + 90°
```

该 90° 带着它的理由写在代码里，而不是作为一个修正量。

### 2.4 三重验证

| 验证 | 结果 |
|---|---|
| 复现 Phase 10F 的经验值 | `θ_m=0` 时 **150.0000°** ✓ |
| 对照**独立求解**的空载磁链 | `λ_A/peak` vs `cos(θ_d)`：0.001~0.018 ✓ |
| 随转子旋转正确移动 | `θ_m` 每增 1°机 → `θ_d` 增 8°电，误差 < 0.07° ✓ |
| **换一台机器是否改变** | Q=24/2p=16 → **150°**；Q=36/2p=12 → **210°**；Q=12/2p=10 → **135°** ✓ |

最后一项是区分「推导」与「硬编码」的关键，已固化为测试
`test_the_alignment_is_not_hard_coded_to_the_reference_machine`。

## 3. abc 电流生成（Step 3）

幅值不变型反 Park，单一约定：

```
ia = id·cos(θ_e) − iq·sin(θ_e)
ib, ic 依次滞后 120°、240°电
```

`θ_e` 即 §2 的励磁基准。**幅值不变**意味着 `id`、`iq` 是相**峰值**量：
`id=0` 时相电流峰值就是 `iq`。

测试覆盖：六个角度上 `ia+ib+ic = 0`（绝对误差 < 1e-12）、
`id=0` 时峰值等于 `iq`、纯 d 轴与纯 q 轴电流向量正交、零电流给零相电流。

## 4. 绕组拓扑与 q（Step 4）

```
q = Q / (2p·m)
```

分类规则：

| 条件 | 分类 |
|---|---|
| `q ≥ 1` 且为整数 | `INTEGER_SLOT_DISTRIBUTED` 整数槽分布 |
| `q < 1` 且节距 ≤ 1 槽 | `FRACTIONAL_SLOT_CONCENTRATED` 分数槽集中（齿绕） |
| 其余分数 `q` | `FRACTIONAL_SLOT_DISTRIBUTED` 分数槽分布 |
| 无法构成平衡绕组 | `UNBALANCED` |

**基线**：Q=24、2p=16、m=3 → **q = 0.5** → 分数槽集中绕组（齿绕）。

## 6. 剖分几何绕组系数（Step 6）

沿用并推广 Phase 10E 的傅里叶投影。**三个量分别命名，绝不合并**：

| 量 | 基线值 | 含义 |
|---|---|---|
| `ideal_slot_star_winding_factor` | **0.8660254** | 位于槽中心的细丝，间隔整数个槽距 |
| `meshed_geometry_winding_factor` | **0.9557520** | 求解器实际剖分的导体分布 |
| `finite_width_factor` | **0.9881902** | 其中有限边宽贡献的部分 |

## 7. 槽几何与可用面积（Step 8）

```
毛面积   = (w_top + w_bottom)/2 · h_slot
可用面积 = 扣除楔块、槽绝缘（周边）、间隙之后的梯形面积
```

槽绝缘沿周边铺设，因此在两个宽度和深度上各扣两倍厚度。
**可用面积不做非负截断**：若允许量本身就放不下，返回负值并给出警告，
而不是悄悄归零。

原有实现只扣楔块，不含槽绝缘、间隙与装填，且只算裸铜，
在仪表板中标注为「近似裸铜槽占比」。本阶段保留该历史量不动。

## 8. 导体面积（Step 9）

区分**裸铜**与**带绝缘包络**：

```
裸铜面积   = π·(d_bare/2)²    · 并绕股数
包络面积   = π·(d_insul/2)²   · 并绕股数
```

未提供绝缘线径时回退到裸铜线径，**并明确警告槽占比被低估**；
`d_insul < d_bare` 直接拒绝。

## 10. 装填系数与阈值（Step 11–12）

圆线无法完美铺满槽。**装填系数是工程假设，不是物理常数**：
它取决于线规、绕制方式、机绕还是手绕。

```
DEFAULT_PACKING_FACTOR = 0.80        ENGINEERING_ASSUMPTION
```

可行性阈值带（按可用面积包络占比除以装填系数）：

| 带 | 状态 |
|---|---|
| ≤ 0.60 | `COMFORTABLE` 宽裕 |
| ≤ 0.75 | `FEASIBLE` 可行 |
| ≤ 1.00 | `TIGHT` 偏紧 |
| > 1.00 | `OVERFILLED` 超填充（绕不进） |

**同样标注为 `ENGINEERING_ASSUMPTION`，并在 GUI 中可编辑。**
**计算结果与建议相互独立**：用户不认可阈值带，依然拿得到数字。

## 11. 一致性检查（Step 13）

**任何情况下都不把设计悄悄裁剪到「刚好装得下」。** 会发出警告的情形：

- 绝缘包络面积超过装填系数下的可达面积
- 可用面积占比 > 100 %（几何上就放不下，与装填系数无关）
- 可用槽面积 ≤ 0（允许量本身放不下）
- 每线圈匝数非整数（应视为串并联折算后的等效匝数）
- 未提供绝缘线径（占比被低估）
- 并绕股线 > 1 且无绝缘线径（股间绝缘与间隙完全未计）
- `d_insul < d_bare` → 直接拒绝，不是警告

## 14. 生产集成提案（Step 16）

**本阶段没有改动受保护的生产物理，也没有替换生产的 `k_w` 来源。**

现状：`motor_core` 通过 `resolve_winding_factor` 消费 `k_w`，
其模式包含 `AUTO_GEOMETRY`（槽电势星形图）与 `MANUAL_USER`。
**手工 `k_w` 目前仍然是生产权威值**（出厂预设即为 0.93）。

### 提案 C —— 生产 `k_w` 默认改用几何推导值

- **现状**：预设与用户输入的 `k_w` 直接进入反电动势公式
- **提案**：几何足够时默认使用 `AUTO_GEOMETRY`，手工值降级为显式覆盖
- **影响**：基线 `k_w` 0.93 → 0.8660254，反电动势与 Ke **下降约 6.9 %**，
  进而影响电压裕度、可行性判定与优化目标
- **向后兼容**：**破坏性**。所有历史项目文件的 Ke / 电压数字都会变化
- **状态**：`FORMULA / SEMANTICS CHANGE PROPOSAL`，**不在本阶段实施**

### 提案 D —— 验证桥的 `k_w` 与生产的 `k_w` 是不同的量

Phase 10E 已让验证桥使用剖分几何值（0.9558）。
**该值不应进入生产**：它描述的是二维展开切片中被剖分的导体布局，
而生产公式要的是真实三维绕组的基波投影。二者恰好接近，但不是同一个量。

## 15. 已知局限

- 槽满率按梯形槽解析计算，不做真实排线仿真
- 装填系数为单一标量，未按线规或绕制方式细分
- 可行性阈值带无公开标准出处，纯属工程惯例
- 每线圈边匝数由每相串联匝数均摊得到，未建模不等匝线圈
- d 轴推导假设磁钢极性由充磁方向 ±90° 表达（当前几何生成器如此）
- 斜槽仅通过 `ks` 体现，未做三维斜槽建模
- 最小复核只覆盖一个设计、一个工作点
- **仍然没有任何物理台架数据**
