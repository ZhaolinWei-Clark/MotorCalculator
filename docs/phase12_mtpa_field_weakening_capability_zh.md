## 1. dq 约定（Step 1）

本仓库已有 dq 模型（dynamics 沙盒）、电轴约定（10G）与同基电压权威（9C）。
若能力求解器另立一套 Park 变换，或在别人用峰值的地方用有效值，
产生的数字会与应用其余部分不一致，而且**没人看得出为什么**。

因此约定在 `capability/conventions.py` 中**声明一次**，其余模块全部从那里读取。

```
Park 变换：幅值不变型（AMPLITUDE_INVARIANT）
```

由此**直接决定**：

| 量 | 基准 |
|---|---|
| id, iq | **相电流峰值**（不是有效值） |
| vd, vq | **相电压峰值**（不是有效值） |
| 转矩式系数 | 3/2（属于该变换） |
| ψ_pm | 每相基波磁链峰值，开路相反电动势峰值 = ω_e·ψ_pm |
| ω_e | 电角速度 = p·ω_m |
| ω_m | 机械角速度 |

**符号取自 `dynamics/pmsm_model.py` 的导数置零**，因此能力求解器就是本项目
已在仿真的那台机器的稳态：

```
vd = Rs·id − ω_e·Lq·iq
vq = Rs·iq + ω_e·(Ld·id + ψ_pm)
```

测试直接断言这一点：把能力求解器算出的 (vd, vq) 回代进
`PMSMDynamicModel.compute_electrical_derivatives`，两个导数均为 0。

所有电抗用 **ω_e**，所有机械功率用 **ω_m**。二者相差 p 倍（参考设计上是 8），
因此本包中**没有任何一个变量只叫 omega**。

## 2. 电流 / 电压基准（Steps 5, 3）

项目以**相有效值**存储电流；dq 电流圆的约束是**峰值**。二者相差 **41.4 %**。

```python
Imax_peak = √2 · Imax_rms          # 显式，绝不省略
```

`current_limit_from_rms()` 存在的全部意义就是这一步换算，
其返回对象同时携带两个基准的数值，因此下游无需假设任何一边。

## 3. 逆变器电压上限（Step 4）

电压上限是峰值/有效值混淆危害最大的地方：每一种看似合理的约定之间
相差 1.15 到 1.73 倍，而**它们都叫「电压上限」**。所以推导写出来：

### SVPWM 线性上限

三相逆变器可实现的电压矢量构成**外接圆半径 2·Vdc/3** 的六边形。
其中可内接的最大**圆**半径等于六边形的内切圆半径：

```
r = (2·Vdc/3) · cos30° = (2·Vdc/3) · (√3/2) = Vdc/√3
```

圆内调制为线性、输出无畸变。在幅值不变变换下，该半径**就是**可用的相电压峰值：

```
V_phase_peak_max = Vdc/√3  ≈ 0.5774·Vdc
V_phase_rms_max  = Vdc/√6  ≈ 0.4082·Vdc
V_line_rms_max   = Vdc/√2  ≈ 0.7071·Vdc
```

`dynamics/modulation/svpwm.py` 已用 `Vdc/√3` 作为线性包络，二者一致。

### SPWM 线性上限

无三次谐波注入时各相独立围绕中点调制：

```
V_phase_peak_max = Vdc/2 = 0.5·Vdc
```

SVPWM 高出 **2/√3 = 1.1547**，即熟知的 15.47 %。
GUI 冒烟断言这个比值精确成立。

### 电压利用率

实际驱动器不会跑到线性区边缘——电流调节器需要裕度。
支持可配置系数，**默认 1.0**，并在任何出现的地方标注：

```
ENGINEERING_ASSUMPTION
```

它**不是物理常数**，也**绝不会被悄悄并入**任何限值。
`utilization > 1` 会被拒绝：那意味着过调制，本稳态求解器不建模过调制。

## 4. MTPA（Steps 6-8）

### 4.1 非凸极：id = 0，**恰好为零**

```
Ld == Lq  →  id = 0.0（字面值，不是数值极限）
```

测试断言 `point.id_a == 0.0`，不是 `approx(0.0)`。
`Ld == Lq` 时 d 轴电流对转矩**毫无贡献**，只消耗电流，
因此答案是精确的零，而不是某个除零极限的结果。

### 4.2 凸极：闭式解，由一次求导得到

固定电流幅值 Is 时：

```
T/(1.5p) = (ψ + (Ld−Lq)·id) · √(Is² − id²)

d/d id = 0
    ⇒  2·ΔL·id² − ψ·id − ΔL·Is² = 0 ,   ΔL = Lq − Ld
    ⇒  id = [ψ − √(ψ² + 8·ΔL²·Is²)] / (4·ΔL)
```

取负根，即对常规内置式永磁机器产生正磁阻转矩的那一支。
ΔL → 0 时该二次式退化，代码**不做除法**，直接返回非凸极结果。

### 4.3 闭式解是被检验的，不是被信任的

`mtpa_condition_residual()` **独立地**计算驻点条件本身，
测试断言闭式解代入后残差为 0（绝对容差 1e−12）。

另有 `verify_mtpa_numerically()` 用**完全不共享任何代数**的暴力扫描交叉核对，
测试断言两者一致。

反凸极（Ld > Lq）**没有被假设掉**：同一式子自然给出 id > 0，测试覆盖。

## 5. 基速（Step 9）

**基速定义为：满电流 MTPA 工作点首次触及电压上限的转速。**

它由机器与逆变器**共同**决定。**基速不是额定转速**，二者只会偶然相等——
测试专门断言参考设计上两者不相等。

求解用二分法（电压幅值对 ω_e 单调），并报告：

```
rpm / ω_e / 电压利用率 / 电流利用率
```

参考设计（V_dc = 48 V，SVPWM，利用率 1.0）：

```
基速 = 1310.5 rpm      电压利用率 = 1.000000     电流利用率 = 1.0000
```

测试断言基速略下方 MTPA 点可行、略上方不可行。

## 6. 弱磁（Steps 10-11）

### 6.1 求解器是闭式的，不是黑箱优化

核心来自一个观察：

> **固定 id、固定转速时，|V|² 是关于 iq 的二次式。**

令 `vd = A + B·iq`、`vq = C + D·iq`，其中

```
A = Rs·id,  B = −ω_e·Lq,  C = ω_e·(Ld·id + ψ),  D = Rs
|V|² = (B²+D²)·iq² + 2(AB+CD)·iq + (A²+C²)
```

于是**该 id 下电压上限允许的最大 iq 有闭式解**。
电流圆给出另一个界：`iq ≤ √(Imax² − id²)`。
而固定 id 时转矩对 iq 单调（只要 `dT/diq = 1.5p(ψ + (Ld−Lq)·id) > 0`），
因此**最优 iq 就是两个界中的较小者**。

二维约束极大化因此**坍缩为对 id 的一维扫描，每一步都有精确答案**，
再用黄金分割在已知区间内细化——那是对标量的**包围法**，不是对物理的优化器。

`dT/diq ≤ 0` 时增加 iq 不再带来转矩，这正是条件本身在告诉我们
已越过最大转矩/电压轨迹（MTPV）。该情形被**尊重**，而不是被夹紧掩盖。

### 6.2 运行区间由**起作用的约束**判定

**绝不**用转速阈值判定——转速是结果，不是原因。

| 区间 | 判据 |
|---|---|
| `MTPA_CURRENT_LIMITED` | 仅电流圆起作用（恒转矩区） |
| `CURRENT_AND_VOLTAGE_LIMITED` | 电流圆与电压椭圆同时起作用 |
| `VOLTAGE_LIMITED_FIELD_WEAKENING` | 仅电压椭圆起作用（深度弱磁 / MTPV） |
| `NO_FEASIBLE_OPERATING_POINT` | 两约束交集中无正转矩点 |

参考设计三个区间**全部出现**。

## 7. 最高转速（Step 12）

二分搜索最高的、**实际求解出**可行且产生正转矩的转速。**从不外推**。

参考设计的结果值得说明：

```
特征电流 ψ_pm/Ld = 13.955 A（峰值）
电流上限 Imax    = 15.978 A（峰值）
```

**Imax > 特征电流**，因此该机器在本模型下**不存在有限的电磁最高转速**：
id 收敛到 −13.955 A（正好是 −ψ/Ld），转矩趋于零但始终为正。
报告的 60000 rpm 是**搜索上限**，并明确标注 `bounded = False`，
而不是伪装成一个物理极限。真正的限制是机械的（轴承、应力），不在本模型范围内。

测试用一台 `Imax = 0.5 × 特征电流` 的机器断言反向情形：**有界**的最高转速。

## 9. 恒功率（Step 15）

**是否存在恒功率区是结果，不是目标。**

测量方式：在基速以上搜索**最宽的、功率波动在阈值内的连续区间**。
之所以不直接取「基速以上全部点的波动」，是因为紧邻拐点上方功率仍在从恒转矩区
爬升，把那段爬坡计入会让一台**明显有**平台的机器被报成没有平台。
搜索最宽平坦窗口是在**测量平台实际所在的位置**，而不是制造一个平台——
没有平坦段的机器仍然返回 `exists = False`，测试用一台低电流上限的机器断言这一点。

```
CONSTANT_POWER_FLATNESS_TOLERANCE = 0.05
classification = ENGINEERING_REPORTING_THRESHOLD
```

该阈值只决定我们**如何称呼**这个区间，**绝不影响任何计算**。

参考设计：

```
最宽平坦区 2412 – 60000 rpm（跨度 24.88×）
功率波动 2.33 %，平均功率 549.4 W  →  判定为恒功率区
```

## 10. 参数来源（Steps 16-18）

### 10.1 ψ_pm —— 单一来源

生产模型有**两条**路径可得 ψ_pm：

```
ψ_pm = Ke_phase_peak_per_mechanical_rad_s / p
ψ_pm = √2 · E_phase_rms / ω_e
```

二者在参考设计上**逐位相同**（0.015938775040747390 Wb），因为本就是同一个量的两种写法。
**一致不是保留两条路径的理由，而是挑一条、到处用它、把另一条记为交叉核对的理由。**
`bridge_from_analysis()` 是本包**唯一**读取生产结果的地方。

### 10.2 Ld / Lq —— 同步电感，不是自感

**这是本阶段唯一的实质性陷阱。**

dq 方程需要的是**同步电感** `L_s = L_ph − M`，不是自感。
生产模型的字段名与直觉相反：

| 字段 | 实际含义 |
|---|---|
| `phase_inductance_h` | **自感** L_ph |
| `line_inductance_h` | **每相同步电感** L_ph − M（尽管名字叫 line） |
| `phase_synchronous_inductance_h` | Phase 9C 为此加的**明确别名** |

本桥接读取**别名**。参考设计上二者相差 **15 %**（0.99313 vs 1.14210 mH）。

来源标记：

```
ISOTROPIC_ASSUMPTION        # 生产只提供一个同步电感，故 Ld = Lq = Ls
```

这是**工程假设**，不是测量：本软件**不会凭空制造凸极性**。
若实际机器为凸极结构，磁阻转矩与弱磁能力都会被低估。
用户可显式提供 Ld 与 Lq，来源标记随之变为 `USER_SUPPLIED_SALIENT`。

### 10.3 Rs

取生产模型的相电阻，并记录其绕组温度（参考设计 80 °C）。
**不做任何额外温度修正**。

## 11. 电压权威交叉核对（Step 22）—— 抓到了一个真实缺陷

这是本阶段最有价值的一步。

在 `id = 0`、`Ld = Lq`、同电流基准、同磁链基准的条件下，
新的 dq 稳态电压必须与 Phase 9C 的 `CORRECTED_SAME_BASIS_PMSM` 一致：

```
|V|_phase_peak = √((ω_e·L·iq)² + (Rs·iq + ω_e·ψ)²)
除以 √2 → |V|_phase_rms = √((I_rms·ω_e·L)² + (E_rms + I_rms·Rs)²)
乘以 √3 → 线有效值，正是 9C 权威的表达式
```

### 第一次运行：相差 −6.86 %

按 Step 22 的要求**停下来诊断**。原因是本阶段的桥接读了
`phase_inductance_h`（自感）而不是同步电感。

### 修正后

```
Phase 9C 权威（margin = 1.0）  : 59.140277984873 V 线有效值
Phase 12 dq → 线有效值         : 59.140277984873 V 线有效值
相对差                          : 4.44e−14 %
```

并且连同生产自带的 1.05 工程裕度系数一起比较时：

```
生产报告的所需电压 : 66.671864807221 V
dq × 1.05          : 66.671864807221 V
相对差              : 0.000e+00 %
```

**这条核对本身就是本阶段最强的正确性证据**，并且它确实抓住了一个
在别处完全看不见的错误。两条断言已固化为测试。

### 低速转矩交叉核对（Step 21）

同基准下必须精确相等，无需解释任何差异：

```
T = 1.5·p·ψ·iq   与   Kt_per_peak_a · iq   逐位一致
且在额定电流下复现生产的额定转矩 3.056 N·m
```

## 14. 局限

- 稳态模型：**不含**铁耗、磁饱和、逆变器开关动态、死区与过调制。
- 转矩为**电磁转矩**，未扣除摩擦与风阻，因此不等于轴端输出转矩。
- 功率为 `T_em·ω_m`，不是轴端输出功率，也未扣除任何损耗。
- 参考设计的 Ld = Lq 来自 `ISOTROPIC_ASSUMPTION`，凸极机器的能力会被低估。
- 电感为常数，**不随电流饱和**；深度弱磁下实际 Ld 会下降，实际能力与本模型会偏离。
- 温度固定：Rs 取生产模型在设定绕组温度下的值，ψ_pm 不随磁体温度变化。
- 最高转速仅为**电磁**极限；机械极限（轴承、应力、动平衡）不在本模型范围内。
- 恒功率的 5 % 阈值是**报告阈值**，不是物理判据。
- **全部结果未经任何实验验证。**

## 15. 实验验证状态

**当前 AFPM 设计仍然：`NOT_EXPERIMENTALLY_VALIDATED`。**

Phase 12 增加的是**能力模型**，不是证据。它没有引入任何测量数据，
也没有改变 Phase 11A/11B 建立的证据分级。

## 16. 是否可以发布

**可以发布为一个新的候选版本，但建议先补两件小事。**

理由：

1. 受保护生产物理 **0 字节改动**，回归 1441 → 1508 全绿；
2. 与 Phase 9C 电压权威**精确一致**，与 dynamics 仿真模型**稳态一致**；
3. 实际打包产物冒烟通过，含全部能力视图、图形与导出；
4. 新增能力为**纯增量**：不打开能力视图的用户完全不受影响。

### 发布前建议补的两件事

1. **合并 Phase 10/11/12 堆叠分支**。目前 `main` 仍停在 `777ef3d`，
   10D 起的全部工作都在未合并的堆叠分支上。这是发布前最大的单项风险
   ——不是技术风险，而是「已完成的工作没有进入主线」的流程风险。
2. **版本号与发行说明**。当前仍标 `1.0.0-rc4`；Phase 12 是面向用户的新能力，
   应提升到 `1.0.0-rc5`（或直接 `1.0.0`，若决定结束候选阶段）。

## 17. 推荐的发布 / 用户反馈下一步

按顺序：

1. **合并堆叠分支到 main**（fast-forward 或显式合并提交，不改写历史）。
2. **提升版本号至 `1.0.0-rc5`**，重建安装包，走 Phase 10H.1 已验证的打包产品门。
3. **发布给真实用户，并明确征集三件事**：
   - 他们的机器是否为**凸极**——这是 `ISOTROPIC_ASSUMPTION` 最需要真实反馈的地方；
   - 他们实际使用的**电压利用率**（本软件默认 1.0，真实驱动器通常 0.90–0.95）；
   - 他们是否有**任何台架数据**——哪怕只有一条空载反电动势曲线。
4. **Phase 13 的方向由第 3 步的反馈决定**，而不是现在预先设定。

特别地：本项目至今**没有一条自有实验数据**，这是 Phase 11A 起就写明的、
也是唯一能把任何量提升为「已验证」的途径。Phase 12 让软件更有用，
但它没有、也不可能改变这一点。
