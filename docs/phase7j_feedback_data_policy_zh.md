# Phase 7J 验证反馈数据政策

## 1. 默认边界

验证反馈默认只保存在本机 `validation_data/user_feedback/feedback_records.jsonl`。Phase 7J 没有网络客户端、上传 API、遥测、云同步或后台导出功能。主 GUI 也未接入该模块。

## 2. 用户控制

用户决定是否导出、共享或版本控制反馈记录。支持文件仍由用户控制；Phase 7J 当前只允许保存可选 `source_file_hash` 和来源引用，不复制或上传原始文件。分享前应检查隐私、商业机密和来源许可。

## 3. 数据用途

反馈是 evidence input，不是参数更新指令。系统允许：

- 保存预测值、参考值、双侧语义和运行点；
- 保存完整输入快照、模型版本和 Git commit；
- 在语义可比时计算描述性误差；
- 生成覆盖度和偏差候选摘要。

系统禁止：

- 自动模型训练或参数校准；
- 根据一条用户记录生成修正系数；
- 隐藏冲突、低质量或重复证据；
- 把 `UNVERIFIED` 数据提升为受控实验。

## 4. 完整性与删除

每条记录保存 `input_snapshot_hash` 和 `record_content_hash`。JSONL 服务采用追加模式并拒绝重复 `record_id`。Phase 7J 不提供自动删除或覆盖操作；如用户决定清理本地记录，应先保留其所需审计副本。

## 5. 未来导出

未来可以在明确用户操作下增加去标识化导出器。该导出必须默认关闭，显示字段预览，并把导出行为与校准审批分离。
