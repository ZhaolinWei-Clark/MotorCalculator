## 2. 生成 Lua 中被真实求解器否决的四条假设

Phase 10A 的单元测试全部通过，但它们只能检验脚本的**结构**。
真实执行否决了四条假设 —— 这正是把 bring-up 排在电机模型之前的原因。

| # | 假设 | 真实行为 | 证据 |
|---|---|---|---|
| 1 | `mi_addsegment` 会创建端点 | **不会**，它连接两个**已存在**的节点 | `.poly` 文件头写着 `0` 节点、`0` 线段；网格器什么也没收到 |
| 2 | 存在 `mo_getb` | **不存在**；点查询是 `mo_getpointvalues`，返回 `A, Bx, By` | 探测脚本直接验证 |

| 4 | 区域材料名 `conductor` 有效 | 脚本定义的是 `copper`；FEMM **不报错**，只是把标签的 block type 置 0（无材料），随后分析拒绝划网格 | `.fem` 中 48 个绕组标签 `BlockType=0`，对照可用模型为 `1`/`2` |

已确认**符合**假设的调用：`mo_getcircuitproperties`、`mo_blockintegral(18/19)`、
`mo_groupselectblock`、`mo_numelements`、`mi_probdef`、`mi_addmaterial`、
`mi_addcircprop`、`mi_setblockprop`、`mi_analyze`、`mi_loadsolution`。

另外确认：**Lua 字符串中用正斜杠路径可行**，因此改用正斜杠，
彻底消除 Windows 路径反斜杠转义这一整类缺陷
（一个漏转义的 `\a` 会变成响铃字符）。

### 同一批运行暴露的两个几何缺陷

- **接缝上的重叠共线线段**：横跨整个宽度的区域（转子磁轭、有铁芯定子铁芯）
  把自己的竖直边画在了求解域侧边之上。重叠共线线段是非法的网格器输入。

## 6. 相映射缺陷：真实求解器发现的最重要问题

第一次真实扫描给出三条**幅值几乎完全相等**（不平衡 0.0043%）的磁链波形，
但它们的**和在任何位置都不为零**，最大达 3.2e-2，而基波只有 1.6e-2。

基波相位：**150° / 90° / 30°** —— 相隔 **60°**，不是 120°。

**原因**：`PHASE_LABELS[belt % m]` 看起来合理，但它给出
A+, B+, C+, A−, B−, C−，把三相排在**相邻**的带上（60 电角度）。
带位于 `180/m` 的整数倍上，相 `j` 应居于带 `2j`，其反向带在 `2j + m`：

```
belt 0 -> A+   belt 1 -> C-   belt 2 -> B+
belt 3 -> A-   belt 4 -> C+   belt 5 -> B-
```

修正后同一扫描：

| 指标 | 值 |
|---|---|
| A−B | **120.001°** |
| B−C | **119.999°** |
| 幅值不平衡 | **0.0028 %** |
| 直流分量 | 8.5e-9 / 3.2e-9 / 1.7e-8 |
| 零序（三相和） | 3.235e-4 = 基波的 **2.035 %** |

零序残差**不是缺陷**：它恰好等于 3 倍的 0.67% 三次谐波，
三次谐波是同相分量，本来就不会在相加中抵消。

> **`motor_core/winding_factor.py` 未被修改。** `build_slot_star` 只提取 A 相，
> 而 A 相的带（0 与 3）在两种映射下相同，因此解析绕组系数从未受影响。
> 回归测试对每个平衡槽极组合逐槽复核 A 相与解析星形图一致。

**FEMM 把 turns 属性存成整数**，磁链因此被低估 4%。

## 8. ⚠ 首次真实 Ke 对比：数字与它真正的含义

### 8.1 基准冻结（Step 15）

- **每相量**（非线量），除非另行标注
- **RMS 取自一个电周期**
- 分母为 **机械 rad/s**
- Y 接无中线，故线电压不含三次谐波，线值由**基波**相 RMS 乘 √3 得到

### 8.2 数字（Step 17）

| 量 | 解析 | FEMM | 绝对差 | 相对差 |
|---|---:|---:|---:|---:|
| `Ke_phase_rms`（含谐波） | 0.09016333 | 0.08996783 | −1.955e−04 | **−0.2168 %** |
| `Ke_phase_rms`（仅基波） | 0.09016333 | 0.08994641 | −2.169e−04 | −0.2406 % |
| `Ke_phase_peak` | 0.12751020 | 0.12334532 | −4.165e−03 | −3.2663 % |
| `Ke_line_rms` | 0.15616746 | 0.15579175 | −3.757e−04 | −0.2406 % |
| `E_phase_rms` @2500 rpm | 23.60470389 V | 23.55352227 V | −5.118e−02 | −0.2168 % |

单位均为 `V·s/rad`（机械），电压为 V。

`Ke_phase_peak` 差得更多（−3.27%）是**波形形状**差异，不是幅值误差：
解析模型假设纯正弦（峰值 = √2×RMS），而真实波形因 2.02% 三次谐波略呈平顶。

### 8.3 ⚠ 这个 0.22% 是两个 7% 误差相互抵消的结果

反电动势对比在数学上只能检验**乘积** `N · k_w · Φ`，因为磁链就是这个乘积。
把它拆开：

| 项 | 值 | 说明 |
|---|---:|---|
| 所求解绕组的几何绕组系数 | **0.8660254** | Q=24、2p=16、节距 1 槽（整距 1.5 槽）：`k_d=1.0`、`k_p=sin(60°)` |
| 解析模型中**手工输入**的 k_w | **0.93** | 参考设计的输入值 |
| **k_w 偏差** | **+7.39 %** | |
| FEA 推出的基波每极磁通 | 0.0003672047 Wb | `λ_基波 / (N · k_w_几何)` |
| 解析集总每极磁通 | 0.0003429919 Wb | |
| **每极磁通偏差** | **−7.06 %** | 解析值偏低 |
| 乘积 `N·k_w·Φ` | — | **−0.31 %** |

**Q=24 / 2p=16 上不存在任何整数线圈节距能给出 k_w = 0.93。**
0.93 是一个与该几何不对应的手工输入值。

诊断性换算（**未修改任何解析输入**）：若解析模型使用与几何一致的
`k_w = 0.866025`，解析 Ke 将为 `0.08396100`，
即比 FEMM **低 7.15 %**。

> **因此正确的读法是**：
> 在与几何一致的绕组系数下，**解析集总磁路把基波每极磁通低估了约 7%**，
> 而输入的 k_w 恰好高出约 7%，两者在 Ke 上相互抵消。
> **单看 0.22% 会得出错误结论。**

这一发现已写入对比本身：新增
`winding_factor_entered_vs_solved_geometry` 指标（0.93 vs 0.8660，−6.879%，
`MODERATE_DEVIATION`），并使整条证据记录的总体判定为
**`MODERATE_DEVIATION`** 而非 `CLOSE_AGREEMENT`。

## 9. 导数交叉校验（Step 14）

| 方法 | RMS | 峰值 |
|---|---:|---:|
| 谱微分（生产方法） | 23.55352227 V | 32.29172935 V |
| 周期中心差分（诊断） | 23.49596380 V | 32.25219687 V |

差异被完全解释：中心差分对第 `k` 次谐波的增益是 `sinc(2πk/N)`。

—— 与实测 0.2444% 吻合。谱微分对带限周期信号是精确的。
**未引入第二套生产公式**；中心差分仅作诊断。
