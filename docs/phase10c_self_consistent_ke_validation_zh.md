## 1. 为什么需要 Phase 10C

```

```

**必须先消除绕组系数的不一致，Ke 残差才能被读作磁路模型形式差异。**

## 5. 双哈希架构缺陷及修复（Step 11）

Phase 10C 的核心实验（只改解析 k_w）暴露了 Phase 10A 双哈希的**行为完全反了**：

| | 修复前 | 应有行为 |
|---|---|---|
| `case_id`（求解器可见） | **变了** ✗ | 不应变——求解器看到的几何完全相同 |
| analytical fingerprint | **没变** ✗ | 应变——对比依赖 k_w |

原因：`winding_factor_analytical` 与 `winding_factor_provenance` 挂在绕组映射上，
但它们**从不进入生成的 Lua**。把它们留在 `case_id` 里，
意味着一次纯解析编辑就"发明了一台新电机"，并丢弃了一份对它仍然完全有效的场解。

**修复**（只动 provenance/哈希架构，不动物理）：

- 这两个字段移出求解器可见摘要（`CASE_HASH_EXCLUDED_NESTED_FIELDS`）
- 移入解析指纹（`ANALYTICAL_FINGERPRINT_EXTRA_FIELDS`）
- 摘要定义变了，故版本提升为 **`phase10c.fea.hash.v2`**，跨版本摘要不可比较

修复后实测：

```
case_id      53fce1b7...  ==  53fce1b7...      （相同 ✓）
fingerprint  b8165385...  !=  bbc698e7...      （不同 ✓）
线圈节距 1→2 仍然改变 case_id                    （✓）
```

冻结的 Phase 10B 产物保留其 v1 下的 `case_id`，并在 README 中说明。

## 9. 误差抵消的定量分解（Step 9）

**乘性**分解，不用加性近似 —— `Ke ∝ N·k_w·Φ` 是乘积，误差按乘积复合。

| | 量 | 值 | 百分比 |
|---|---|---:|---:|
| **A** | 绕组系数比 `k_w_manual / k_w_geom` | `1.073871500692704` | **+7.3872 %** |
| **B** | 磁通比 `Φ_解析 / Φ_FEA` | `0.9340619771027402` | **−6.5938 %** |
| **C** | 历史净 Ke 比 `Ke_old / Ke_FEA` | `1.0021729924204905` | −0.2168 %（FEA 相对解析） |
| **D** | 自洽净 Ke 比 `Ke_new / Ke_FEA` | `0.9332336241105532` | **+7.1543 %** |

### 重建校验

```
A × B                                   = 1.0030625370913138
朴素残差                                 = +8.895e-04     ← 不为零
```

残差**不是噪声**，由两个已知的基准因子精确解释：

| 因子 | 值 | 说明 |
|---|---:|---|
| `LEGACY_SINE_EMF_FACTOR / (2π/√2)` | `0.9993511109343879` | 解析模型用**取整的 4.44**，精确值为 4.442882938…，使解析 Ke 偏低 **0.0649 %** |
| FEA 总 RMS / 基波 RMS | `1.0002381508583695` | FEA 的 Ke 是**含谐波的总 RMS**，而磁通比基于**基波** |

```
A × B × sine / harmonic                 = 1.0021729924204903
观测 C                                   = 1.0021729924204905
精确残差                                 = -2.220e-16   ← 机器精度
```

**分解在机器精度内精确闭合。** `cancellation_confirmed = True`。

> 注意：`4.44` 这一取整是既有的 legacy 常量，**本阶段只报告，未修改**。

## 16. 建议的 Phase 10D 范围

**不要**在此残差被分离之前做转矩验证——否则会把同一个未分离的 7 % 带进转矩结论。

建议的受控实验，用于分离 §13 中的假说 1 与 2：

1. **把 `leakage_factor` 设为 1.0 重算解析**（仅诊断，不改默认值），
   观察残差从 +7.06 % 移动多少 → 直接量化假说 2 的贡献。
2. **从 FEA 场直接积分每极磁通**（沿气隙线对 `B_y` 积分），
   同时给出**总磁通**与**基波磁通**，与解析集总 `Φ` 逐项比较
   → 直接检验假说 1，无需经由磁链与绕组系数反推。
3. 若 1 与 2 合起来解释了大部分残差，再考虑是否值得作为公式变更提案
   （仍须走 Phase 9 那样的正式审批流程，本阶段不预判）。
