# Phase 8I：v1.0.0-rc1 稳定化与最终验收

## 发布边界

Phase 8I 只接通并验证既有能力。没有修改电磁、动态控制、热、不确定性或校准数学；没有切换 production 公式或默认模型。

## 分析入口

- `分析 -> 动态仿真`：仅 PMSM。用户显式设置仿真时长、精度预设、目标/初始转速、负载、J 和 B。`Rs` 来自当前静态相电阻，`Ld=Lq` 来自标量相电感，`psi_f` 由 PMSM 相峰值电流口径 Kt 显式换算。输入变化后必须重新静态计算，不能使用 stale 结果。
- `分析 -> 不确定性分析`：显式样本数和 seed，复用 Phase 7I 受控参考假设。结果不代表当前 production 结果的总误差。
- `分析 -> 敏感性分析`：复用 Phase 6A 副本扰动，固定 `-5/-1/+1/+5%`，不优化、不校准、不写回。

## 性能与线程决策

验收规模的分析运行时间短，不足以证明引入后台线程和取消状态机的复杂度合理。因此 RC 保持同步显式运行；长时间自定义运行的取消功能延期。Tk 控件仍只在主线程操作。

## DPI 结论

旧输入面板采用自适应标签列宽、换行和现有垂直滚动；分析窗口按屏幕尺寸约束，参数区采用紧凑网格，图表区保留独立工具栏。源码和打包版都覆盖了 96 DPI 与模拟 200% DPI。200% 截图中主窗口实际为 1824x980，Windows 工作区为 1920x1032；关键输入、仪表板、分析窗口和对话框无裁切或任务栏遮挡。输入面板在高缩放下继续通过垂直滚动访问完整字段。

## Windows 发布验收

- PyInstaller 6.16.0 one-folder、Portable ZIP 和 Inno Setup 6.7.3 安装包均由提交 `ee4ed136db870099f4b5b77a40595df2ec13b563` 构建。
- 安装包大小 30,002,231 bytes；Portable ZIP 大小 41,547,663 bytes；one-folder 共 91,102,924 bytes / 1,248 个文件；实际安装目录共 95,839,677 bytes（91.4 MiB）/ 1,250 个文件。安装目录额外包含 Inno Setup 卸载器数据，因此不得与 dist 大小混为一谈。
- 打包版和 Portable 均从仓库外目录运行，清除了 `PYTHONHOME`、`PYTHONPATH`、`TCL_LIBRARY`、`TK_LIBRARY`，且未使用源码 `.venv`。Tcl/Tk 8.6.15 运行资源完整。
- 真实安装路径为 `%LOCALAPPDATA%\Programs\MotorCalculator`。开始菜单快捷方式启动了响应正常的中文 RC 主窗口；桌面快捷方式保持可选且默认关闭。
- 真实执行了 0.9.0 安装、0.9.0 GUI smoke、稳定 AppId 原位升级、RC GUI smoke、实际卸载器卸载和 RC 重装。旧 `.motorproj`、恢复/反馈数据及用户数据标记均保留。
- Microsoft Defender 4.18.26060.3008-0 对安装包、安装版 EXE 和 Portable EXE 的扫描均为未发现威胁。
- 安装包和 EXE 均为 `NotSigned`。静默本地测试未观察到 SmartScreen；这不等于干净机器不会显示未知发布者或信誉提示。

## 干净环境门禁

本机 Windows Sandbox 不可用；VMware 可执行，但仅发现带 PLC 环境的 Windows VM 和 Ubuntu VM，没有可证明为一次性干净 Windows 的基线。因此 `TRUE_CLEAN_MACHINE_TEST = BLOCKED_BY_ENVIRONMENT`。不得把本地验收替代为真干净机器证据。

## 发布结论

本地结论为 `RC_ACCEPTED_LOCALLY`：638 项完整回归和 46 项部署/RC 专项测试通过，源码、打包、Portable、安装、升级、卸载与重装门禁通过，受保护哈希不变。由于真干净 Windows 验收仍为 `BLOCKED_BY_ENVIRONMENT` 且发布未签名，不建议把此 RC 直接改称最终公开 v1.0.0。
