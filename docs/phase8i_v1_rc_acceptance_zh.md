# Phase 8I：v1.0.0-rc1 稳定化与最终验收

## 发布边界

Phase 8I 只接通并验证既有能力。没有修改电磁、动态控制、热、不确定性或校准数学；没有切换 production 公式或默认模型。

## 分析入口

- `分析 -> 动态仿真`：仅 PMSM。用户显式设置仿真时长、精度预设、目标/初始转速、负载、J 和 B。`Rs` 来自当前静态相电阻，`Ld=Lq` 来自标量相电感，`psi_f` 由 PMSM 相峰值电流口径 Kt 显式换算。输入变化后必须重新静态计算，不能使用 stale 结果。
- `分析 -> 不确定性分析`：显式样本数和 seed，复用 Phase 7I 受控参考假设。结果不代表当前 production 结果的总误差。
- `分析 -> 敏感性分析`：复用 Phase 6A 副本扰动，固定 `-5/-1/+1/+5%`，不优化、不校准、不写回。

## 性能与线程决策

验收规模的分析运行时间短，不足以证明引入后台线程和取消状态机的复杂度合理。因此 RC 保持同步显式运行；长时间自定义运行的取消功能延期。Tk 控件仍只在主线程操作。

## DPI 结论

旧输入面板采用自适应标签列宽、换行和现有垂直滚动；分析窗口按屏幕尺寸约束，参数区采用紧凑网格，图表区保留独立工具栏。验证覆盖 96 DPI 与现有基础设施模拟的 200% DPI；最终打包版仍需重复验证。

## 发布结论

最终状态必须在完整回归、源码/打包/安装/Portable GUI、真实 0.9.0 升级和保护哈希门禁结束后填写。真正干净 Windows 环境若不可用，应保持 `BLOCKED_BY_ENVIRONMENT`，不得把 RC 称为最终公开 v1.0.0。
