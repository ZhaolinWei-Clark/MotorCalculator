# Phase 10D — 磁通残差分解与磁路诊断

**状态**：`FLUX_RESIDUAL_FULLY_DECOMPOSED`
**分支**：`validation/phase10d-flux-residual-decomposition`
**基线**：`main` @ `777ef3d`（已发布 `v1.0.0-rc4`）
**应用版本**：`1.0.0-rc4`（Phase 10D 不提升版本号）
**求解器**：FEMM 4.2.0.0，**新增 5 次求解**（见 §3.1，说明为何必须重跑）

> **一句话结论**：+7.15 % 的 Ke 残差**不是**磁路幅值误差。
> 解析磁路对气隙磁密**峰值**的预测误差只有 **−0.059 %**。
> 残差由四个可测因子相乘而成，其中最大的一项是
> **Phase 10C 使用的绕组系数并不描述 FEMM 实际剖分的绕组**。
> 四项相乘后与实测残差的差为 **−0.001 %**。
> **本阶段只做测量，没有做任何校准，没有改动生产物理量。**

## 1. 动机

Phase 10C 把历史上那个"极佳"的 −0.22 % 一致性判定为误差抵消，并在统一绕组系数
后暴露出 **+7.15 %** 的 Ke 残差与 **+7.06 %** 的"磁通残差"。网格敏感性只有
0.050 %，比残差小 143 倍，所以它不是离散化问题。

但 Phase 10C 的"磁通残差"是**反推**出来的：

```
Phi_FEA = lambda_fundamental / (N * k_w)
```

这条路径的可信度完全取决于用来"除回去"的那个 `k_w`。它无法区分
**磁路误差**与**定义不匹配**，因为两者都表现为同一个数字。

Phase 10D 的任务就是补上**独立的第二条路径**：直接采样求解后的气隙场。

## 3. 直接气隙磁场提取

### 3.1 为什么必须重跑 FEMM

Phase 10B/10C 保留的结果里**只有**每相电路磁链和一个块积分力，
**从未写出任何气隙场采样**。直接积分所需的数据在冻结证据中根本不存在。

代价被刻意压到最低：空间谐波分解只需要**单个转子位置**的场分布。
本阶段共 5 次求解（1 次主探针 + 1 次轴向剖面 + 3 次半径切片），
**不是** 52 点扫掠。

### 3.2 方法

新增 `motor_calculator/fea/airgap_probe.py`：复用**生产环境同一套**几何、
材料与网格发射器，只替换后处理——不再问 FEMM 要电路磁链，而是沿等 `y` 线
采样点场值，同时记录 `A_z` 与 `B`。

### 3.3 术语（本阶段禁止使用含糊的"每极磁通"）

| 名称 | 定义 |
|---|---|
| `signed_pole_flux` | 一个极距上 `B_n` 的积分 × 径向长度，带符号 |
| `absolute_pole_flux` | 全跨度 `\|B_n\|` 积分 / 极数 × 径向长度 |
| `fundamental_flux_per_pole` | `(2/pi) * B1_peak * tau_p * L`，仅基波 |

`E = 4.44 f N k_w Phi` 这条公式要求的是**第三个**。

### 3.4 结果（定子中面 y = 0）

```
FEMM 峰值 |B_n|       0.678643 T
解析磁密峰值           0.679045 T
峰值一致性             -0.0592 %      <-- 磁路幅值几乎完全正确
FEMM 基波 B1          0.707400 T
FEMM THD（>=2 次）     3.367 %
```

`A` 路径与 `B` 路径在每个平面上一致到 **< 0.09 %**，说明提取本身是自洽的。

## 4. 两条 FEA 磁通路径不一致 —— 先查约定

直接法给出 3.249952e-04 Wb，磁链反推法给出 3.672046e-04 Wb，
**相差 −11.50 %**。按规程必须先诊断提取约定，不得据此指责解析模型。

### 4.1 轴向剖面

绕组厚 5 mm，场沿轴向变化显著：

```
 y [mm]    Phi1 [Wb]        区域
  0.000   3.249952e-04     线圈（定子中面）
  1.250   3.307563e-04     线圈
  2.500   3.485586e-04     线圈表面
  3.000   3.592733e-04     机械气隙
  3.500   3.719760e-04     磁钢表面
```

磁链反推值 3.672e-04 对应 **y ≈ 3.2 mm**，**完全落在线圈之外**。这说明
反推路径本身有问题，而不是场有问题。

### 4.2 闭环验证

用采样到的 `A` 场按 FEMM 自己的定义重建电路磁链
（`sum(signed_turns * depth * <A_z>)`），与 FEMM 自己报告的磁链比较：

```
A 相：重建 -1.379863e-02   FEMM -1.378836e-02   比值 1.000745
B 相：重建 +1.379245e-02   FEMM +1.378833e-02   比值 1.000298
```

**一致到 0.075 %** —— 绕组模型已被完全理解。

## 5. 核心发现：被剖分的绕组不是星形图假设的那个绕组

模型使用 `SIDE_BY_SIDE_DOUBLE_LAYER_GO_THEN_RETURN`：一个线圈的两条边落在
**相邻层位**上，因此中心距是**一个槽距 + 一个层宽**，而不是一个槽距。
同时每条边有 3.5 mm 的有限宽度，不是细丝。

| 量 | 值 |
|---|---|
| 极距 tau_p | 20.6167 mm |
| 槽距 | 13.7445 mm |
| 线圈边宽度（层宽） | 3.5000 mm |
| **实际剖分的线圈节距** | **17.2445 mm = 1.2546 槽距 = 0.8364 极距** |
| 节距系数 `sin(pi/2 * 0.8364)` | 0.967174 |
| 有限宽度系数 `sinc(pi w / 2 tau)` | 0.988190 |
| **剖分绕组的 k_w** | **0.955752** |
| Phase 10C 使用的星形图 k_w | 0.866025 |
| 比值 | **1.103607** |

两条**完全独立**的路径互相印证：

```
路径 1（几何）  0.955752
路径 2（场）    0.957506      <- lambda_peak / (N * Phi1_线圈平均)
一致性          +0.1835 %
```

**Phase 10C 的"自洽"并不自洽**：它修正了"输入 0.93 vs 星形图 0.866"这一个
不匹配，却没有察觉 FEA 几何的有效 k_w 是 0.9558。

## 6. 残差预算（乘法）

`Ke ∝ k_w * Phi`，各分量按**乘积**合成：

| 分量 | 因子 | 百分比 |
|---|---:|---:|
| 绕组系数：剖分几何 vs Phase 10C 星形图 | 1.103607 | **+10.361 %** |
| 约定：平顶磁通用在需要基波的公式里 | 1.031747 | +3.175 % |
| 波形 + 线圈轴向平均（无铁芯厚气隙） | 0.940453 | **−5.955 %** |
| 4.44 舍入 vs 精确 `2*pi/sqrt(2)` | 1.000649 | +0.065 % |
| **四项之积** | **1.071536** | **+7.154 %** |
| **实测 Ke 残差** | 1.071543 | +7.154 % |
| **未解释余量** | 0.999993 | **−0.001 %** |

**`INTERACTION_PRESENT` 不适用**：四个因子相乘即可复现实测值，
余量 −0.001 % 属数值噪声。

### 6.1 波形分量的证据

```
解析磁密峰值                 0.679045 T
FEMM 定子中面峰值            0.678643 T     一致 -0.0592 %
FEMM 实测 B1/B_peak          1.042375
理想 alpha_p=0.7 矩形        1.134465
纯正弦                       1.000000
FEMM THD                     3.367 %
```

在 7 mm 等效气隙、5 mm 磁钢的无铁芯机中，定子中面的场**已经接近正弦**
（THD 3.4 %），而解析模型假设的是 THD 约 27 % 的 0.7 矩形波。
**峰值对了，波形不对。**

## 7. 单因素诊断（全部 `DIAGNOSTIC_ONLY`，未改任何默认值）

### 7.1 漏磁系数（Step 4）

| sigma_m | 解析磁通 | 相对默认 |
|---|---|---|
| 1.00 | 3.726454e-04 | +8.646 % |
| 1.05 | 3.622072e-04 | +5.602 % |
| 1.10 | 3.523377e-04 | +2.725 % |
| **1.15（生产默认）** | 3.429919e-04 | 参考 |
| 1.20 | 3.341291e-04 | −2.584 % |

`sigma_m = 1.0` 会让解析磁通**上升** 8.65 %，把 FEA-vs-解析从 −2.97 %
推到 **−10.69 %** —— **严重过校正**。漏磁系数**不是**残差的来源，
把它调成 1.0 会让一致性更差。

### 7.2 等效气隙 / Carter（Step 8）

生产模型：`g_eff = h_coil + 2g = 7 mm`，`slot_type = 无槽` 时 Carter = 1.0。

**对无铁芯 AFPM 这是正确的**：解析等效气隙就是两个磁钢面之间的真实空间，
没有齿槽，因此不应套用有槽径向电机的 Carter 系数。
把磁钢等效厚度再加进气隙（`+2*h_m/mu_r`）会造成 −34.7 % 的磁通塌陷，
属于**重复计入**磁钢磁阻，明确错误。

### 7.3 磁钢有限磁导率（Step 9）

生产模型**已经**按有限磁导率处理：`mu_r` 同时出现在磁钢磁阻与 MMF 中，
因此 `F / R_mag = Br * A` 精确成立。`mu_r = 1.05` 与 FEMM 材料一致。
**无发现**。

### 7.4 磁钢极弧 / 边缘效应（Step 10）

`alpha_p` 同时进入 `A_pole` 的分子分母，在 `B_peak` 中**相消**，
只线性缩放总磁通。因此 `alpha_p` 无法解释"峰值正确但基波不足"这一现象；
真正的机制是**边缘扩散使波形趋于正弦**，已计入 §6 的波形分量。

### 7.5 平均半径近似（Step 11）

三个独立 2D 切片（**不是 3D 解**）：

| 切片 | 半径 | tau_p | h_m/tau_p | B1（线圈平均） |
|---|---|---|---|---|
| 内 | 35.00 mm | 13.744 mm | 0.3638 | 0.621914 T |
| 中 | 52.50 mm | 20.617 mm | 0.2425 | 0.724907 T |
| 外 | 70.00 mm | 27.489 mm | 0.1819 | 0.769734 T |

```
B1 内->外 变化         +23.769 %
径向积分基波磁通        3.323232e-04 Wb
平均半径切片           3.330040e-04 Wb
平均半径误差           +0.2049 %
```

`B1` 沿半径变化很大，但因为磁通权重正比于 `r`，两者**大部分相互补偿**，
平均半径近似只贡献 **+0.20 %**。

**结论：平均半径近似是 `SMALL`，不是主导项。**

## 10. 公式变更决定

### **`MORE_VALIDATION_REQUIRED`**

**生产物理（`motor_core/calculations.py`）不需要变更，且本阶段未变更。**
证据反而支持现有磁路：气隙磁密峰值预测误差仅 −0.059 %，漏磁系数、
等效气隙与磁钢磁导率处理都经得起单因素检验。

真正需要处理的是**验证桥**与**约定**，两者都不属于受保护的生产物理：

#### 提案 A —— 验证比较层应使用被剖分绕组的 k_w（缺陷修复）

- **现状**：`comparison.py` 用槽电势星形图的 `k_w` 反推"FEA 等效磁通"
- **提案**：改用由 `FEASliceModel` 区域几何直接测得的 `k_w`
  （`flux_budget.meshed_winding_factor`）
- **依据**：几何与场两条独立路径一致到 0.18 %
- **影响**：Phase 10B/10C 的"磁通残差"数字会被取代；**Ke 比较本身不受影响**
  （Ke 比较从不使用该反推值）
- **向后兼容**：历史证据保持冻结，按既有政策跨版本不可比较
- **风险**：低。不触碰任何解析物理

#### 提案 B —— 解析磁通在代入 `4.44` 公式前应转换到基波基准

- **旧式**：`E = 4.44 * f * N * k_w * Phi_平顶`
- **新式**：`E = 4.44 * f * N * k_w * Phi_平顶 * (8/pi^2) * sin(alpha_p*pi/2) / alpha_p`
- **物理推导**：幅值 `B`、占极距 `alpha_p` 的平顶波，其空间基波幅值为
  `(4/pi) B sin(alpha_p pi/2)`，对应每极基波磁通
  `(8/pi^2) B tau L sin(alpha_p pi/2)`；而 `4.44` 公式要求的正是基波磁通
- **量纲检查**：修正因子无量纲（`sin` 的宗量为弧度），量纲不变
- **预期影响**：`alpha_p = 0.7` 时解析 Ke **上升 3.17 %**；
  注意该因子在 `alpha_p ≈ 0.742` 处穿过 1，宽极弧时**反向**
- **受影响输出**：反电动势、Ke、Kt、电压裕度、可行性判定、优化目标
- **向后兼容**：**破坏性**。所有历史 Ke/电压数字都会变化
- **需要的验证**：至少 3 个不同 `alpha_p`、不同气隙比例的设计上重复 Phase 10D；
  并且**必须有物理台架数据**才能判定哪一种基准更接近真实机器

**提案 B 不应在缺少实验数据的情况下实施。** FEMM 与解析模型都不是真值；
把解析值改到与单一 2D FEA 案例一致，正是 Phase 10C 明确禁止的校准行为。
