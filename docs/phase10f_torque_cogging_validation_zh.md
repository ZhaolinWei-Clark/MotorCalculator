## 3. 转矩语义映射（Part A）

项目中至少有六个量都叫"转矩"，其中只有一部分是物理模型的输出。

| 名称 | 定义 | 方程 | 负载条件 | 来源 | 含损耗 | 基准 |
|---|---|---|---|---|---|---|
| `rated_torque_nm` | 由额定输出功率与转速直接得到的**轴端**转矩 | `T = P_rated/ω_mech` | 额定点（按定义） | `DERIVED_FROM_INPUT` | 是 | `SHAFT_OUTPUT` |
| `average_torque_nm` | 生产模型直接返回 `rated_torque_nm` | 同上 | 额定点 | `DERIVED_FROM_INPUT` | 是 | `SHAFT_OUTPUT` |
| **`electromagnetic_torque_same_basis_nm`** | 由反电动势与相电流经功率平衡得到的**气隙电磁**转矩 | `T_em = 3·E_ph_rms·I_ph_rms/ω_mech` | `id=0, iq=I` | `ANALYTICAL_MODEL` | 否 | **`ELECTROMAGNETIC_AIRGAP`** |
| **`femm_block_integral_torque_nm`** | 转子块加权 Maxwell 应力积分 × 平均半径 | `T = F_x·r_mean`，`F_x = mo_blockintegral(18)` | 案例激励 | `NUMERICAL_FEA` | 否 | **`ELECTROMAGNETIC_AIRGAP`** |
| `torque_ripple_percent` | 由用户输入的 6 次与 12 次系数合成 | `T(θ)=T_rated(1+k6cos6θ_e+k12cos12θ_e)` | 额定点 | `EMPIRICAL_INPUT` | 是 | `EMPIRICAL_RATIO_OF_RATED` |
| `cogging_torque_peak_nm` | 用户输入的齿槽系数 × 额定转矩 × 形状因子 | `= 0` 当无铁芯 | 零电流 | `EMPIRICAL_INPUT` | 否 | `EMPIRICAL_RATIO_OF_RATED` |

**本阶段要避免的陷阱**：`rated_torque_nm` 是**轴端**量且**由输入派生**，
磁路设计改变时它一动不动；FEMM 报告的是**电磁**转矩。
直接相比会把"一个假设与一次测量之差"报告成模型残差。

`assert_same_basis()` 在基准不一致时**抛异常**，而不是返回一个看似合理的数字。

## 5. FEMM 转矩提取（Part C）

- **量**：`mo_blockintegral(18)`，加权 Maxwell 应力张量 x 方向力
- **积分区域**：`ROTOR_GROUPS`（上下两个转子组：磁钢 + 转子磁轭）
- **转矩换算**：`T = F_x · r_mean`（展开平面模型，深度 = 径向有效长度）
- **对称性缩放**：无。模型跨越整个圆周，`NONE_FULL_CIRCUMFERENCE`
- **周期性**：转矩扫掠跨一个电周期；齿槽扫掠跨一个齿槽周期
- **未使用**磁链反推路径（Phase 10D 已判定其非独立）

## 6. 发现并修复的两个验证桥缺陷

### 6.1 安匝缺陷（已修复，6.25 倍）

首轮加载扫掠在**三个设计上**都给出约 **−0.46 N·m**，而同基准解析值是 **+3.056 N·m**。
这不是残差。

**根因**：绕组区域写入**单位匝数**（±1），以规避 FEMM 把 `turns` 属性存为整数
从而把 6.25 匝截断成 6 匝的问题。对**空载磁链**这是精确的——磁链对匝数线性，
提取后再乘回 6.25 即可。

但对**加载求解**不成立：电枢磁场取决于**安匝**。以 1 匝代替 6.25 匝求解，
模型中的电枢磁动势只有真实值的 1/6.25，由此导出的任何转矩都小 6.25 倍。

**零求解代价的验证**（非салient 机器能量守恒）：

```
T(θ) = Σ_k e_k(θ)·i_k(θ) / ω_mech
```

`e_k` 取自**复用的**空载磁链扫掠，`i_k` 取自验证桥自己的 `balanced_phase_currents`：

```
能量守恒预测（偏置 0°）   -2.835190 N·m
FEMM 块积分实测           -0.457035 N·m
比值                       6.2034
unit_turns_scale           6.2500
预测 / 6.25 = -0.453630 vs 实测 -0.457035  →  吻合 0.745 %
```

**修复**：把电路电流同样乘以该因子，安匝即精确恢复。

**关键约束**：空载脚本**逐字节不变**（归一化 SHA-256 仍为
`8fbb95e9...cb96e9`），因为零电流乘以任何因子仍为零。
Phase 10B/10C/10D 的证据完全未受影响，并由测试固化该哈希。

### 6.2 电角度对齐缺陷（未修复，留给 Phase 10G）

验证桥以 `electrical_alignment_offset_deg = 0` 注入电流，但转子 d 轴在
`rotor_angle_mech = 0` 处位于 **150° 电角度**。

**推导而非拟合**：该处空载磁链为 `λ_A = −0.866·λ_peak`、`λ_B = +0.866·λ_peak`、
`λ_C ≈ 0`。相绕组在 d 轴与自身轴线重合时链到峰值磁通，
故 `cos(θ_d) = −0.866` 且 `λ_B > 0` 给出 `θ_d = 150°`。
独立的 24 点软件扫掠也在 150° 取得最大转矩，二者一致。

**本阶段未修复**：正确的修复属于放置磁钢的几何层，不应在验证脚本里打补丁。
本阶段的扫掠显式传入推导出的 150°，并在证据中记录。

## 7. 核心发现：转矩对比不是独立验证（Part E）

生产模型按下式反解相电流：

```
I_ph_rms = T_rated / Kt_rms ,   Kt_rms = 3·E_ph_rms / ω_mech
```

于是同基准解析电磁转矩

```
T_em = Kt_rms · I_ph_rms = Kt_rms · (T_rated / Kt_rms) ≡ T_rated
```

**恒等成立**。三个设计的解析 `T_em` 全部等于 3.056000 N·m，与磁路设计无关。

因此 `T_FEMM / T_解析 ≈ Ke_FEMM / Ke_解析`，对比重新检验的是 `Kt`，
也就是 `k_w·Φ`——Phase 10D/10E 已经验证过的那个量。

## 9. 转矩扫掠策略（Part D）

仓库默认策略解析到 18 次电谐波，需要每设计 73 次加载求解。
本阶段问的是三个问题：均值、峰峰脉动、主导脉动谐波。

**25 点**：一个电周期上等间隔 25 点，均值对**低于 25 次的所有谐波精确**
（会折叠到直流的混叠需要 25 次及以上），6 次与 12 次分别有 4.2 与 2.1 点/周期。
升到 73 点买到的是 13~18 次谐波的分辨率——本阶段并不问这些——代价是三倍求解量。

**求解计数**：转矩 3×25 = 75，齿槽 3×24 = 72，合计 **147 次**。
对齐诊断为**零次新求解**（复用空载扫掠）。

## 10. 齿槽转矩（Part G/H）

**条件**：零定子电流，仅永磁励磁。
**跨度**：一个齿槽周期 = `360/lcm(24,16)` = **7.5 机械度**，24 个采样点。

| 网格档 | 缩放 | 峰峰值 | 占额定转矩 | 单元数 |
|---|---|---|---|---|
| COARSE | ×1.6 | 0.18701424 N·m | 6.12 % | 91 667 |
| BASE | ×1.0 | 0.11878613 N·m | 3.89 % | 121 877 |
| FINE | ×0.625 | 0.06308167 N·m | 2.06 % | 215 225 |

```
COARSE → BASE  -36.5 %
BASE   → FINE  -46.9 %
```

**峰峰值随每次加密接近减半，正在收敛到零。**

这与物理一致：**无槽定子没有齿槽转矩**。FEMM 侧的"信号"完全是
每个转子位置重新剖分网格带来的离散化噪声（单元数在扫掠内本身就在
114 094~121 877 之间波动）。

**网格敏感性与信号幅值同量级，因此该信号不能与数值误差区分开。**

## 11. 解析齿槽转矩的状态（Part I）

```python
if i.is_coreless:
    return rotor_position_rad, np.zeros_like(rotor_position_rad)
```

对无铁芯设计，解析齿槽转矩**结构性恒为零**。这是一个**假设**，不是模型预测。

对有铁芯设计：`T_cog_peak = shape_factor · k_cogging · T_rated`，
其中 `k_cogging` 是 GUI 中的**用户输入字段**（"齿槽转矩系数"）。

分类：

- 无铁芯：**`NO_ANALYTICAL_MODEL`** —— 没有可与 FEMM 比较的解析量
- 有铁芯：**`EMPIRICAL_INPUT`** —— 是经验输入而非首要原理模型

**不存在"FEMM 与解析齿槽一致"这种说法，因为没有解析模型可一致。**

## 13. 决定（Part L）

### 平均转矩：**`MORE_VALIDATION_REQUIRED`**

**不是** `NUMERICALLY_VALIDATED`，理由有三：

1. **对比不独立**。相电流由额定转矩反解，`T_解析 ≡ T_额定` 恒成立，
   对比重新检验的是 `Kt = k_w·Φ`，与 Ke 残差吻合到 0.13 pp。
   这里没有一个"转矩模型"被验证。
2. **对齐缺陷未修复**。本阶段扫掠使用推导出的 150° 偏置，
   而验证桥的默认值仍是 0°。默认路径目前会给出**符号相反**的转矩。
3. **仍无实测数据**。

**解析模型没有被本阶段证伪**：安匝缺陷与对齐缺陷都在验证桥内。

### 齿槽转矩：**`NO_ANALYTICAL_MODEL`**

对本阶段使用的无铁芯设计：解析值按构造恒为零，是假设而非模型；
FEMM 侧的信号随网格加密减半，低于数值噪声底。**两侧都没有可验证的东西。**

若将来验证有铁芯设计，状态将是 `EMPIRICAL_INPUT`，
仍然不能与 FEMM 结果作"一致性"声明。

## 15. 建议的 Phase 10G

1. **把推导出的 d 轴对齐写入几何层**，使验证桥默认路径产生正确符号的转矩
2. **对有铁芯设计做齿槽验证**——那里既有真实的齿槽物理，也有一个（经验的）解析量
3. **让转矩成为独立检验**：需要一个不由额定转矩反解电流的工作点，
   例如给定电流扫转矩曲线
4. 转矩的网格敏感性研究，以及固定网格（不逐位置重剖）以压低噪声底
5. **物理台架数据仍是把任何 `NUMERICAL_FEA` 升级为 `VALIDATED` 的唯一途径**
