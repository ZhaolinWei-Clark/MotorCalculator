## 3. Proposal A 的实现（Step 3-4）

新增 `motor_calculator/fea/meshed_winding.py`。

**没有硬编码 0.955752。** 实现方式是对**实际导体分布**做基波投影：

```
C   = Σ_r  signed_turns_r · exp(j k x_center_r) · sinc(k w_r / 2)
k_w = |C| / (2 N)
```

其中 `k = π / τ_p`。这是从定义直接推出的：平面问题中电路磁链是
`Σ signed_turns · depth · <A_z>`，而基波 `A_z` 在有限宽度区域上的平均带来一个
`sinc`。

**自检**（写入测试）：

- 整距细丝线圈 → 恰好 `1.000000`
- 2/3 距细丝线圈 → 恰好 `√3/2 = 0.8660254`

即在星形图正确的地方，通用形式复现星形图。

**基线结果**：

```
Phase 10D 几何路径（节距 × 宽度）  0.955752007
Phase 10E 通用傅里叶投影           0.955752007      (0 ulp)
Phase 10D 场路径（λ / N Φ1）       0.957505939      (+0.183 %)
```

命名按 Step 4 明确区分：`_ideal_slot_star_winding_factor`、
`_meshed_geometry_winding_factor`、`_flux_inversion_winding_factor`。

## 10. 绕组系数发现是否具普遍性

三个设计共享同一绕组，因此**无法**独立检验绕组结论。
补充一个零求解代价的几何扫掠（8 个 slot/pole/span 组合）：

```
差异范围 |mesh/star − 1|   1.180 % .. 10.358 %
全部超过 1 %               是
方向是否一致               否
```

**差异始终显著，但方向不普遍**：理想绕组若是短距，额外的层位移使其靠近整距，
`k_w` 上升；理想绕组若已是整距，位移使其越过整距，加上宽度 sinc，`k_w` 下降。

**因此固定符号的「修正系数」对某些绕组必然是错的——
这正是桥必须去测量几何、而不是套一个系数的原因。**

## 12. Proposal B 重新评估（Step 16）

### **`MORE_VALIDATION_REQUIRED`**（维持不变）

复现**加强**了 Proposal B 的**物理推导**（约定确实变号，量级可观），
但同时**削弱**了实施它的理由：

1. **残差会变号。** 设计 C 是 −14.26 %，解析模型在那里高估。
   把解析磁通乘以 `(8/π²)sin(απ/2)/α` 会让 A、B 更接近 FEMM，

   只改约定因子会把两个不同的问题混在一起。
3. **仍然没有实测数据。** FEMM 与解析都不是真值。

**结论：Proposal B 的推导是站得住的，但证据不支持现在实施。**
它应当与波形项一起处理，而不是单独实施。
