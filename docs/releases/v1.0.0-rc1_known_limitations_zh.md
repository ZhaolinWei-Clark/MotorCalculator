# MotorCalculator v1.0.0-rc1 已知限制

- AFPM 外部验证仍有限，当前证据不足以声称普遍预测精度。
- 参数不确定性分析不是总预测误差；模型形式不确定性尚未完整量化。
- 静态热预测不可用；动态热模型是独立的一阶集中参数沙盒，不等于实体热设计验证。
- 铁损、机械损耗和风阻损耗可能不完整，效率应按模型边界解释。
- BLDC 同基电压裕量语义不足时保持不可用，不以 PMSM 正弦假设替代。
- 速度扫描是逐点重复静态计算，不是真实电机能力包络，也不包含控制器、电流限幅或场弱化能力边界。
- 槽占比是近似裸铜占比，不包含完整绝缘、工艺、槽楔和制造公差模型。
- GUI 动态仿真当前仅支持 PMSM。静态标量相电感映射为 `Ld=Lq` 是明确的表贴式沙盒近似。
- 动态、FOC、逆变器、损耗与热模型属于实验/沙盒层，不是工业控制器或硬件认证模型。
- 不提供制造认证、安全认证、FEA 等价、最优效率或自动校准保证。
- 当前发布未配置可信代码签名，实际签名状态为 `NotSigned`。静默本地安装未观察到 SmartScreen，但新机器仍可能显示未知发布者或信誉提示。
- 真正一次性的干净 Windows 环境为 `BLOCKED_BY_ENVIRONMENT`。现有 Windows VM 带有 PLC 环境，不可冒充干净基线；这是公开 v1.0.0 的阻塞门槛。
- 200% DPI 下输入区依赖现有垂直滚动显示完整高级字段；已验证关键控件、分析窗口和对话框无裁切，但未覆盖所有显示器组合与多屏移动。
- 分析运行保持同步；当前验收规模较短，尚无长时自定义仿真的取消按钮或后台任务状态机。
