# v1.0.0-rc2 模型能力矩阵（Phase 9B Batch A 更新）

状态定义：`SUPPORTED` 可用；`APPROXIMATE` 近似；`EXPERIMENTAL` 沙盒；`UNAVAILABLE` 不可用；`VALIDATION LIMITED` 外部证据有限。

> 本表取代 `v1.0.0-rc1_capability_matrix_zh.md`（后者保留为历史记录）。
> Phase 9B Batch A **未做任何数值变更**，只修正了两项损耗的表述边界。

| 能力 | 状态 | 边界说明 |
|---|---|---|
| PMSM 静态计算 | SUPPORTED / VALIDATION LIMITED | 语义已分离，AFPM 外部精度证据仍有限 |
| BLDC 静态计算 | SUPPORTED / VALIDATION LIMITED | 120° 六步波形语义已验证，部分下游仍为 legacy |
| AFPM 表示 | APPROXIMATE / VALIDATION LIMITED | 默认 SSDR 双转子单定子双气隙；不是 3D FEA |
| 转矩 | SUPPORTED / VALIDATION LIMITED | 同时保留 legacy 与 strict-SI 语义边界 |
| Ke / Kt | SUPPORTED / VALIDATION LIMITED | PMSM/BLDC 口径明确；默认切换政策仍受冻结约束 |
| 绕组系数 k_w1 | SUPPORTED / APPROXIMATE | RC2 起支持槽电势星形图自动计算，带 provenance；仅基波 |
| **所需电压 / 电压裕量** | **APPROXIMATE / 基准待修正** | **legacy 口径已确认存在混合基准与 RSS 合成缺陷（Phase 9 Finding 1）；Phase 9B C1 提供并行修正输出，legacy 仍为默认** |
| 电流密度 | APPROXIMATE | 相 RMS、电流并联支路口径明确；不替代导体热设计 |
| 槽占比 | APPROXIMATE | 裸铜几何近似，缺少完整制造堆叠 |
| 铜耗 | APPROXIMATE | 直流电阻口径，含温度修正；未含交流附加铜耗 |
| **导体涡流损耗** | **EXPERIMENTAL** | **单一气隙峰值磁密标量施加于含端部绕组的全部铜体积；未解析局部/端部/电枢反应/邻近效应/线股位置。中高速工况下可能主导效率估计** |
| **集总磁性损耗（原"铁芯损耗"）** | **APPROXIMATE / EMPIRICAL LUMPED** | **额定输出功率的固定比例，与转速和磁密完全解耦；不是经验证的定子铁芯损耗预测。coreless 下转子背铁与磁钢损耗未建模也未分离，因此不得置零** |
| 机械损耗 | APPROXIMATE | 风损 + 轴承损经验式 |
| 效率 | APPROXIMATE / VALIDATION LIMITED | 继承上述损耗模型边界；受涡流项主导 |
| 静态热 | UNAVAILABLE | 不构造虚假温升 |
| 动态集中参数热 | EXPERIMENTAL | 一阶 RC 沙盒，需显式参数 |
| 速度扫描 | SUPPORTED / APPROXIMATE | **基于当前模型逐点重算，不是完整转矩-转速能力包络。** 损耗模型与转速解耦，效率曲线不可外推 |
| PMSM 动态仿真 | EXPERIMENTAL | dq 电气-机械模型与控制沙盒，用户显式运行 |
| BLDC 动态仿真 | UNAVAILABLE | 未实现 |
| FOC | EXPERIMENTAL | 坐标变换、PI、限压等基础；非工业完整 FOC |
| 齿槽转矩 | APPROXIMATE | 幅值由用户系数给定，非预测；空间频率由 LCM(2p, Q) 决定 |
| 敏感性分析 | SUPPORTED / EXPERIMENTAL | 只读局部扰动，不是优化或校准 |
| 不确定性分析 | EXPERIMENTAL / VALIDATION LIMITED | 受控参考参数不确定性，不等于当前模型真实误差 |
| 外部验证 | VALIDATION LIMITED | 缺少足够 AFPM 电磁直接比较点 |
