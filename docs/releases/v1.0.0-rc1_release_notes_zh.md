# MotorCalculator v1.0.0-rc1 发布说明

## 新增功能

- 中国用户优先的本地 Windows 工程预览应用，统一项目保存、自动恢复、结果仪表板和可制造性起始示例。
- 结果仪表板提供当前静态模型的工程状态、损耗项和实际重复计算的速度扫描，并支持 PNG、SVG、CSV 导出。
- “分析”菜单显式接入既有 PMSM 动态仿真、受控参考不确定性分析和只读参数敏感性分析。所有分析均需用户点击，不在项目加载或普通计算时自动运行。
- 动态仿真提供 FAST、BALANCED、HIGH_ACCURACY 预设；步长仍由既有 Phase 6 数值设置内部决定。

## 主要修复

- 修复旧输入面板在高 DPI 下的标签列宽与换行问题，同时保持 Basic/Advanced 字段隐藏语义。
- RC 版本字符串由单一版本源管理；Windows 文件资源版本从 `1.0.0-rc1` 派生为数字版本 `1.0.0.1`。
- 分析窗口按工作区约束尺寸，图表工具栏和参数区在 96 DPI 与高 DPI 验收中保持可操作。

## 已验证能力

- 静态 PMSM/BLDC 计算、工程可行性提示、项目保存/加载、结果快照、自动恢复、仪表板与速度扫描。
- PMSM 动态控制沙盒、Phase 6A 局部敏感性、Phase 7I 受控参考参数不确定性均通过显式 GUI 入口运行。
- 源码、PyInstaller one-folder、Portable 与本地安装包的验收状态以发布清单和验收报告为准。

## 已知限制

请阅读 [v1.0.0-rc1_known_limitations_zh.md](v1.0.0-rc1_known_limitations_zh.md)。本版本不声称 FEA 等价、制造认证、通用实验精度或优化保证。

## 安装方式

运行 `MotorCalculator-1.0.0-rc1-win64-setup.exe`，使用稳定 AppId 进行当前用户安装。桌面快捷方式为可选且默认不勾选。应用未签名时 Windows 可显示“未知发布者”。

## Portable 使用方式

解压 `MotorCalculator-1.0.0-rc1-win64-portable.zip`，从 `MotorCalculator/MotorCalculator.exe` 启动。无需安装 Python，不应依赖源码仓库或 `.venv`。

## 数据保存位置

应用日志、恢复快照、反馈记录和默认导出目录位于 `%LOCALAPPDATA%\MotorCalculator`。用户创建的 `.motorproj` 位于用户选择的位置，卸载策略不删除这些数据。

## 项目文件兼容性

项目 schema 继续保持 v1。缺少结果快照的旧项目可正常打开；输入变化或应用/模型版本不匹配时，保存的结果只作为历史结果，不会被静默当作当前结果。

## 验证与精度声明

参数不确定性不等于真实模型误差。AFPM 外部电磁验证仍有限，模型形式不确定性尚未完整量化。用户应将本软件视为可复现的工程预览计算器，而不是认证或最终设计依据。
