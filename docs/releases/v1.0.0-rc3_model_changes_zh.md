# v1.0.0-rc3 模型变更说明

> **RC3 的数值输出可能与 RC2 不同。本文档逐项说明为什么、差多少、以及兼容性政策。**

---

## 1. 旧电压语义（RC2 及之前）

```python
required_voltage_v = sqrt(
    E_line_rms**2 + (I_ph_rms * R_line)**2 + (I_ph_rms * omega_e * L_s)**2
) * 1.05
```

三项的实际参考基准（以 72 V / 600 W / 2200 rpm 实测）：

| 项 | 值 | 相对每相量的倍数 | 是否一致 |
|---|---:|---|---|
| `E_line_rms` | 35.290379 V | **√3 ×** 相 | ✅ 线基准 |
| `I_ph · R_line` | 1.140226 V | **2 ×** 相（端子直流口径） | ❌ 非 √3 |
| `I_ph · ω_e · L_s` | 20.663841 V | **1 ×** 相（每相电抗） | ❌ 非 √3 |

**同一根式内混用三种基准**，且三项被 RSS（平方和开方）合成，
而 `id = 0` 时 `E_ph` 与 `I·R_ph` **同相**，只有 `jω_e L_s I` 正交。

---

## 2. 新电压语义（RC3）

```
V_required_line_rms
= √3 · √( (E_phase_rms + I_phase_rms · R_phase)² + (I_phase_rms · ω_e · L_s)² ) · 1.05
```

### 基准定义（每一项都单一且显式）

| 符号 | 含义 | 基准 |
|---|---|---|
| `E_phase_rms` | 相反电动势 | `phase_rms_volt` |
| `I_phase_rms` | 相电流 | `phase_rms_ampere` |
| `R_phase` | 相电阻 | `phase_ohm` |
| `L_s` | 每相同步电感 `L_ph − M` | `phase_synchronous_henry` |
| `ω_e` | 电角速度 | rad/s |
| **结果** | **所需端电压** | **`line_rms_volt`** |

**每一项输入都是每相 RMS 量，仅在最后统一乘 √3 转为线电压 RMS。**

不再使用 legacy 的 `2·R_ph`（端子直流测量口径）与每相电抗混合。

---

## 3. 为什么修改

Phase 9 独立评审把它列为五项发现中**唯一的 `CONFIRMED_FORMULA_DEFECT`**：

1. **基准混用**：`E` √3×相、`I·R` 2×相、`I·X` 1×相。主导项 `I·X` 偏小 **42.3%**。
2. **RSS 而非相量合成**：把同相的 `E` 与 `I·R` 当作正交处理。
3. **方向单一非保守**：在 400–5000 rpm × 200–2000 W 的 96 点网格上，
   相量式结果**恒大于** legacy，最小相对差 **+0.907%**。

---

## 4. 参考方程与 dq 等价性证据

由 Phase 6 `PMSMDynamicModel.compute_electrical_derivatives` 令
`did/dt = diq/dt = 0`、`id = 0`：

```
v_d = −ω_e · L_q · i_q
v_q =  R_s · i_q + ω_e · ψ_f
|V_dq| = hypot(v_d, v_q)                 ← 幅值不变 Park ⇒ 相峰值
V_line_rms = |V_dq| / √2 · √3 · k_margin,     i_q = √2 · I_phase_rms
```

幅值不变约定由 `dynamics/inverter.py` 的 `V_dc/√3` 包络作用于 `hypot(v_d, v_q)` 确认。

**实测等价性**：

```
ψ_f = Kt_peak/(1.5p) = 0.01563397 Wb
ω_e·ψ_f = 28.814474 V   vs   √2·E_ph = 28.814474 V     比值 1.000000

相量式 = 53.509476885063116 V
dq 式  = 53.509476885063116 V            |差| = 0.000e+00
```

测试容差 `1e-12` 相对，实测为 **0**。**没有创建第三条独立公式**：
`voltage_semantics.py` 中两个函数是同一表达式的两种写法，并有测试断言其相等。

### RC3 附加的一致性修正

`analysis_service.py` 的 dq 桥接此前映射 `Ld = Lq = L_ph`（相自感），
而修正静态路径使用 `L_s = L_ph − M`（同步电感），**同一台电机携带两个不同电感**。

RC3 把桥接改为 `L_s`（实测比值 `L_s/L_ph = 1.15`）。
**dq 方程本身未修改**，有逐项断言的测试。修正后，静态修正相量电压与
经桥接的 dq 稳态电压相等（1e-12 相对）。

## 6. 兼容性政策

### 保留的 legacy 字段（数值逐位不变）

| 字段 | 说明 |
|---|---|
| `PerformanceResult.required_voltage_v` | **被冻结基线锚定**，逐位不变 |
| `PerformanceResult.legacy_required_voltage_v` | 上者的显式别名 |
| `PerformanceResult.voltage_margin_percent` | legacy 直流母线差额，逐位不变 |
| `assessment.legacy_required_voltage_line_rms_v` | legacy 所需电压 |
| `assessment.legacy_voltage_margin_percent` | 以 legacy 电压计算的同基裕量 |
| 导出键 `legacy_required_voltage_v` / `legacy_voltage_margin_percent` | 仅以 `legacy_` 前缀导出 |
| 仪表板 `legacy_diagnostic_metrics` 分组 | 标注为「兼容值」 |
| 速度扫描 `legacy_required_voltage` 曲线 | `default_visible=False` |

**legacy 值不再驱动**：可行性严重度、优化器接受与排序、仪表板主 KPI、
正常报告结论、正常导出的权威字段。

### 迁移元数据

`voltage_margin_percent`（在 `DesignFeasibilityAssessment` 上）**语义已改变**——
它现在承载权威修正裕量。这不是静默重解释：同时提供了

- `voltage_model_provenance` = `CORRECTED_SAME_BASIS_PMSM` / `LEGACY_MIXED_BASIS_REFERENCE`
- `voltage_semantics_version` = `phase9c.voltage.v1`
- `legacy_voltage_margin_percent` 显式承载旧值

### 命名别名（新增，不移除旧名）

| 新别名 | 旧名 | 说明 |
|---|---|---|
| `terminal_resistance_ohm` | `line_resistance_ohm` | 端子直流电阻 `2·R_ph`，**不是** √3 关系 |
| `phase_synchronous_inductance_h` | `line_inductance_h` | 每相同步电感 `L_ph − M`，**不是**线间电感 |
| `required_voltage_line_rms_v` | — | 权威所需电压 |
| `voltage_margin_line_rms_percent` | — | 权威裕量别名 |

RC3 **不移除**任何旧名称。

### 项目与快照

- `.motorproj` 输入语义**未改变**，输入哈希**未改变**，schema 仍为 v1。
- 老项目**可正常加载**。
- 重新计算时结果会不同（这是权威口径变更的预期后果）。
- 结果快照带 `result_model_version = APPLICATION_VERSION`，
  因此 RC2 快照在 RC3 中被标记为 `历史结果，需要重新计算`，不会被当作 RC3 结果展示。

### BLDC

**未改变。** BLDC 没有正弦相量基准，因此：

- `required_voltage_line_rms_v` = `None`
- `voltage_authority` = `LEGACY_MIXED_BASIS_REFERENCE`
- `voltage_status` = `NOT_ENOUGH_SEMANTICS`
- 仍发出 `VOLTAGE_BASIS_UNAVAILABLE`

**未在 Phase 9C 中伪造 BLDC 等价物。**
