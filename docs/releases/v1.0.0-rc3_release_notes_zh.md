**发布通道**：`release-candidate`（**不是公开 v1.0**）

## 1. 修正 PMSM 电压语义已提升为权威路径

Phase 9 独立评审把 legacy `required_voltage_v` 判定为五项发现中
**唯一的 `CONFIRMED_FORMULA_DEFECT`**：同一根式内混用三种参考基准，
且把同相的项当作正交做 RSS 合成。Phase 9B 已把修正值作为并行输出发布并通过全部门禁；
**RC3 将其提升为权威工程结果**。

```
V_required_line_rms
= √3 · √( (E_phase_rms + I_phase_rms·R_phase)² + (I_phase_rms·ω_e·L_s)² ) · 1.05
```

自 RC3 起，对受支持的 PMSM 计算：

- **修正同基电压 = 权威工程值**
- **legacy 电压 = 兼容/参考值，不再驱动任何工程结论**

应用中**不再存在两个相互竞争的、面向用户的工程结论**。

## 2. dq / 静态电感一致性修正

`analysis_service.py` 的 dq 桥接此前映射 `Ld = Lq = L_ph`（相自感），
而修正静态路径使用 `L_s = L_ph − M`（每相同步电感），
**同一台电机在两条路径上携带不同电感**（实测比值 1.15）。

RC3 把桥接统一为 `L_s`。**dq 方程本身未修改**（有逐项断言的测试）。
修正后，静态修正相量电压与经桥接的 dq 稳态电压**相等到 1e-12 相对**。

## 6. 仪表板、图表与导出迁移

- **仪表板**：`所需线电压 RMS` 与 `同基电压裕量` 主卡片显示权威值；
  legacy 数值移入新的「兼容值」诊断分组，不再与主 KPI 并列。
- **速度扫描**：每个转速点重算权威所需电压与权威裕量；
  legacy 对比曲线存在但 `default_visible = False`。
  作用域声明保持不变：**「基于当前模型逐点重算，不是完整转矩-转速能力包络。」**
- **导出**：`required_voltage_line_rms_v`、`available_voltage_line_rms_v`、
  `voltage_margin_line_rms_percent` 承载权威值；
  legacy 值**只以** `legacy_required_voltage_v` / `legacy_voltage_margin_percent` 导出。
  另附 `voltage_model_provenance` 与 `voltage_semantics_version`。

## 8. BLDC 保持不支持

**未在 RC3 中伪造 BLDC 等价物。** BLDC 缺少正弦相量基准，因此：

- 权威所需电压 = 不可用
- `voltage_status` = `NOT_ENOUGH_SEMANTICS`
- 仍发出 `VOLTAGE_BASIS_UNAVAILABLE`
- legacy 值仍可见，但明确标注为 legacy

## 10. 仍然存在的已知限制

**RC3 未改变任何损耗、热、AFPM、不确定性或动态控制方程。**

- **导体涡流损耗**：`EXPERIMENTAL`。单一气隙峰值磁密标量施加于含端部绕组
  （占铜体积 43.37%）的全部铜体积；未解析局部/端部/电枢反应/邻近效应/线股位置。
  中高速工况下可能主导效率估计。**RC3 未做数值修改。**
- **集总磁性损耗（原「铁芯损耗」）**：`EMPIRICAL_LUMPED`。额定输出功率的固定比例，
  与转速和磁密完全解耦；coreless 下转子背铁与磁钢损耗未建模也未分离，
  因此不得置零。**RC3 未做数值修改。**
- **速度扫描不是完整转矩-转速能力包络**；损耗模型与转速解耦，效率曲线不可外推。
- **静态温升不可用**（不构造虚假温升）。
- **AFPM 外部验证有限**；无 FEA 等价性声明；无制造认证声明。
- **电压修正无外部实验验证**——内部一致性充分（与本项目自身 dq 模型逐位一致），
  但尚未与实测端电压比对。
- **发布未签名**；真干净 Windows 验收状态见发布清单。

## 13. 为什么 RC3 仍不是公开 v1.0

1. **未签名**，公开分发会出现「未知发布者」提示。
2. **真干净 Windows 验收仍被环境阻塞**，本地验收不能替代。
3. **电压修正尚无外部实验验证**——内部一致性充分，但未与实测端电压比对。
4. 两项主导效率的损耗项仍分别为 `EXPERIMENTAL` 与 `EMPIRICAL_LUMPED`。
