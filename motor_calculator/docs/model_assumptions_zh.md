# 模型假设说明

## 1. 当前电机类型

当前模型目标对象为三相轴向磁通永磁无刷电机，覆盖 AFPM PMSM/BLDC 两种运行模式，不再将模型定义为有刷 PMDC。

## 2. 默认拓扑假设

- 默认拓扑为双转子、单定子、双气隙。
- 磁路中的双侧磁钢磁阻和磁动势写法仍保持 legacy 双侧结构假设。
- 若未来支持单转子或单气隙拓扑，需要重新审查相关系数和磁阻表达式。

## 3. 默认连接方式

- 默认绕组连接方式为 Y 接。
- 线电压、线电阻和线电流的定义都基于 Y 接语义。
- 当前阶段未引入三角形接法。

## 4. PMSM 与 BLDC 模式定义

- `PMSM`：正弦反电势、正弦电流。
- `BLDC`：梯形反电势、120° 方波导通。
- 当前阶段只冻结模式定义，不替换 legacy 经验公式。

## 5. 极对数与总极数定义

- `pole_pairs` 表示极对数。
- `pole_count = 2 * pole_pairs` 表示总极数。
- 任何涉及机械角、电角频率和空间周期的计算都应明确使用其中之一，避免混淆。

## 6. 相值、线值、峰值、有效值定义

- `back_emf_phase_rms`：相反电势有效值。
- `back_emf_line_rms`：线反电势有效值。
- `phase_current_rms`：相电流有效值。
- `line_current_rms`：Y 接下与相电流数值相同。
- `phase_voltage_peak`、`phase_voltage_rms`、`line_voltage_rms` 等概念在新内核中已明确命名，但 legacy GUI 展示仍沿用旧字段别名。

## 7. 暂未考虑的物理现象

- 详细退磁校核
- 铁心饱和与局部漏磁分布
- 温升-电阻-磁钢工作点耦合
- 逆变器调制度、死区、电流谐波
- 详细槽满率、绝缘厚度、工艺空间
- 机械应力、转子结构强度与振动噪声

## 8. 适用范围

- 适合做 legacy 工具行为冻结、结构重构和回归比较。
- 适合做快速方案级估算和界面行为保持。

## 9. 不适用范围

- 不适合作为最终电机定型依据。
- 不适合作为退磁、饱和、热设计或机械强度的最终校核模型。
- 不适合用来证明物理精度已经提高；本阶段目标仅是结构可靠性、可测试性和输入安全性。
