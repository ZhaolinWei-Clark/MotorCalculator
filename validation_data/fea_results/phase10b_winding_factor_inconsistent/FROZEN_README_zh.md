## 为什么标注为「绕组系数不自洽」

该对比中，解析侧与 FEA 侧使用了**不同的绕组系数**：

| 项 | 值 |
|---|---|
| 解析模型手工输入的 `k_w` | **0.93**（`manual_user_input_reference_design`） |
| 所求解绕组几何推导的 `k_w` | **0.8660254037844386**（Q=24、2p=16、1 槽节距） |
| 偏差 | **+7.39 %** |

由于 `Ke ∝ N · k_w · Φ`，反电动势对比只能检验这三者的**乘积**。
Phase 10B 观察到的表观一致性

```
Ke_analytical = 0.09016333
Ke_FEMM       = 0.08996783
相对差        ≈ -0.2168 %
```

是**两个约 7% 的误差相互抵消**的结果：绕组系数偏高约 +7.39 %，
解析每极磁通偏低约 −7.06 %。

> **因此 −0.22 % 不能被解读为磁路模型已被验证。**
